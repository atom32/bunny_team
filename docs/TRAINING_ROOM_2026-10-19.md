# 休勤训练室

2026年10月19日，基地增加可操作的3D训练展示。角色会走到器材旁、转身，再开始动作；不是菜单里的静态姿势。沿用现有成年女主模型，未更换 Arcana，未改身体比例、服装、贴图或人物网格。

## 进入与操作

正常入口是基地底部「休息室」→「进入训练室」，不要求先完成校园或水塔任务。结束后「返回休息室」回到原基地，不自动出击。

| 项目 | 动作 |
| --- | --- |
| 体操垫 | 举臂，左右体侧伸展，放下双臂，16秒循环 |
| 跑步机 | 沿后方坡道登上跑带，原地快走；跑带标线向身后移动 |
| 训练凳坐站 | 坐下、短暂停留、起身，再开始下一组 |
| 训练凳休息 | 坐下后停留，不自动起身，也不虚增训练组数 |

- 「暂停动作」冻结姿势与训练计时，镜头仍可手动观察。
- 0.5、1.0、1.25倍播放速度；「结束这组」会离开器材，回到垫边。
- 全身镜头、自动环绕、左右镜头按钮；在空白3D区域按住右键拖动，滚轮调整远近。
- Tab 显示或隐藏界面，Esc 使用原有暂停菜单。
- 不扣物资、不加属性、不增加任务/好感/存档字段；训练时间、动作项目和组数只在本次展示中保留。

三位联系人各有一句短对白，例如唐葵的「放心，没人算你投降。手举高一点。」和休息时的「给你留了位子。……不是叫你起来。」没有把训练写成任务说明会。

## 制作边界

这是基础动作和器材交互原型，不是新战斗玩法或完整健身模拟。运动用现有服装展示，不自动切换运动服。尚未增加手脚IK、抓握约束或衣物/器械物理，脚底与凳面的细节接触仍需精修；骨点高度检查不等于网格碰撞验收。跑步机表现为快走，不宣称已有跑步、俯卧撑或器械力量训练动作。

原生测试和动图来自 RTX 5090；音频使用 Dummy。生成输入不代替陌生玩家或实体手柄测试，也不代表最低配置验收、公开发布或真实80%好评。

原生旧对白与运水车路线的首轮失败保留在final03/build03原日志和首次结果文件，后续串行复查另存`serial_rechecks.json`，不覆盖失败。首次路线失败时有其他原生窗口并行运行，失焦暂停是排查方向，但没有证明它就是两类失败的根因，也没有宣称修复原游戏的对白输入。新训练室本身的170/182/182项均在各自首次检查通过。
