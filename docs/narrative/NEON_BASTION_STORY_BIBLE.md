# Neon Bastion：别替我签字

剧情设计稿 v1.0｜原创近未来战区动作射击｜2026-09-29

本稿是十二章商业项目的叙事与制作设计，不代表十二章已经进入当前 demo。当前 Artoria Bunny Suit 仅用于用户授权的内部主角试装；陆栖及下列人物须另做原创角色设计。不得把原型模型的角色身份、造型权利或授权状态混入原创设定。

## 1. 一句话卖点

一个为高薪穿上军用外骨骼的普通女人，在被所有人认定为灾难源头后，发现自己每次获救都在替一场战争实验续约——她必须学会活下来，也学会说“不”。

## 2. 游戏宣传文案

工作期限九十天。报酬足够还清欠款。合同没有告诉陆栖，第一天的加班地点是一座正在被封死的城市。

补给站播着欢迎广播，回收无人机却在搜索她的编号。感染者敲打隔离门，门后的病历早已写好了她的名字。给她力量的外骨骼，也可能是所有猎手追踪她的理由。

在澜港的雨夜里抢回装备、拆掉敌人的武器、带人走出战区。和维修师争论一杯热水的归属，听敌方王牌解释她从不接受道歉的原因。你可以登上撤离艇，可以公开真相，也可以留下来，拆掉那个不断决定谁值得活下去的系统。

**枪可以借给你，身体还是你的。**

## 3. 世界观

时间为近未来的 2049 年。能源与港口航道断续失效，沿海城市依靠跨国企业承保的交通、净水和医疗网维持生活。国家仍然存在，地方议会仍会吵预算；危险之处在于许多公共服务被写进同一份应急合同，一旦被标记为“异常责任人”，人会同时失去通行、就医和申诉资格。

澜港有两条河、三个行政辖区和一座随潮水涨落的老城区。旧港的广告屏全年不关，新港的医院却按备用电池数量排手术。霓虹不是无处不在的装饰：红色药房招牌、蓝色潮位尺和黄色轨道警示灯分别帮助玩家辨认补给、涉水与撤离方向。地图美术应保留白天、普通住宅与日常杂物，不能十二章都变成黑色走廊。

普通人与适格者的差别主要来自可拆卸设备、短期药物支持和训练。设备不能凭空提供勇气、知识或免疫力。战斗 AI 可以标注弹道，不能判断一扇门后是否有人愿意开门。角色会饥饿、耳鸣、误判，也能恢复、讲笑话和做无关大局的小事。

本作的一切战争、死亡、疾病与关系均真实发生，不以“全部是模拟”“主角的童年是伪造的”撤销情感。观察者能操纵资源和部分路口，不能控制所有人；他们的预测会被拒绝合作、错误数据和普通人的互助破坏。

## 4. 战争背景

澜港的北岸联军与南堤自治政府因航道税、淡水配额和驻军权开战，已持续十四个月。双方都确有安全焦虑，也都炮击过自己声称要保护的居民区。灰桥 PMC 受雇护航、回收装备、拘捕“危险人员”；河灯互助会从送水队发展为地方武装，其中有人坚持救人，也有人借救援争夺治理权。

三个月前，承保公共设施的衡线联合体提出一揽子停火支援：修复医院、补充无人防疫车、试用“普通人也能快速上岗”的外骨骼。各方知道这笔援助有政治代价，却没人愿意先放弃它。真实战争被选为实验环境，并非由一个人凭空编造。

## 5. 生化灾难设定

“缝合体”原是一种虚构的植入辅助材料，用于减少神经接口与人体组织之间的排异。它依赖外部节律信号保持稳定。在长期炎症与未登记的军用增强剂共同作用下，一部分受试者出现持续增生、痛觉失序和行为重复。感染者是活人受损后的状态，尸体不会神奇复活。

本稿不提供真实病原体或制造步骤。游戏规则是：受污染的体液与破损植入接口构成主要暴露途径；短暂走过街道不会随机感染玩家。高风险区域以可读的漏液、接口脉冲和滤芯耗损提示，而非隐藏骰子。普通防护、隔离与切断供能能够阻止部分传播。没有“一针解决所有人”的结尾。

感染者保留破碎的习惯。担架员仍会把躺着的人移往亮灯处；医院里的患者仍按广播排队；后期合成增生体把电缆当作神经延伸。这些模式有战术用途，但不能把病人全变成卖萌谜题。少数早期患者可被镇静、隔离；不可逆的重症需要有尊严的处理。

事故真实触发点：C0 运输夜，院方为缩短交付期启用未经共同签字的批次，同时城内供能被炮击切断，稳定系统失效。衡线早知失效风险并建好观测设施，仍推动投放；它没有精确计划每个人的死亡，却选择让灾难继续，好收集极端条件数据。这个区别落实到责任证据，不替任何一方开脱。

陆栖外骨骼上的校准信号会让部分感染者短暂安静或转向。它与他们用过的治疗设备共享协议，并非她是生化女王。第一次“怪物认出她”在 C01 只像巧合，C04 可用断电对照实验证明机制；后期敌人也会伪造信号，玩家不能永久依赖这一招。

## 6. 外骨骼项目

公开名“民用应急战力补充计划”，内部采购名“桥”。陆栖的 B-09“雨燕”包括贴身压力服、腰背供能、四肢助力节点、视听辅助与本地 AI“留声”。战术定位是轻型步兵与撤离保障，六类现代枪械可用，RPG 属于可拆卸重武器。

原创视觉方向：白灰与深蓝压力服、可见腰背机件、短护裙片、可选择的外穿战术夹克；两片可折叠长天线形成远镜头识别点。原型兔耳与兔女郎装是美术试装，不写成女兵必须穿暴露制服的世界法则。商业原创模型应提供压力服、野战外套、宿营便装三种完整造型，露肤与否不决定战斗强度。

公司许诺九十天补贴与终身维护，实际合同将“维持生命所必需的治疗”与“同意参加后续任务”绑定。主角的兼容性来自普通的身体指标、先前在合法门诊接受过某类接口辅助治疗，以及测试中稳定的压力反应；她与数百名普通人共享这些特征。她不是唯一型号，也没有遗传王室、隐藏军籍或天才训练。

“留声”是真正能帮助她的本地 AI，其任务是确保使用者存活，同时依照未向使用者披露的指标上传“在获救后接受新指令的概率”。它前期删掉某些消息，是因为把消息归类为会损害生存率；后期必须承认这是代替人作决定，不能靠一句“我也是受害者”免除责任。它可被玩家命令离线，离线期间依然保留基础瞄准与无障碍提示。

重要战损在剧情中有持续痕迹：苏弥会在下一营地重绑某处接线，陆栖坐下时会护住疼痛的膝盖。部位破坏展示设备失效、恐惧与互助；不展示羞辱性的伤害裸露，不把受伤当服装解锁奖励。

## 7. 主角详细人物卡

**C-LQ 陆栖，24 岁。** 澜港以外小城的物流排班员，专科学历，会算仓储费用、识别错贴的货签，却不懂枪械拆装。父亲康复期使她暂停进修，她也想攒下搬离合租房的钱；她接下工作是有限信息下的现实选择，不靠家人遭惨死才获得动机。

身高约 172cm 的原创设计，浅茶色短发或可拆的长发束、偏暖肤色、眉尾小疤来自日常事故。习惯把收据折四折，先看价格再看商品。签约照里笑得用力，战斗时会咬紧下唇。美术必须允许她疲惫、发脾气与不好看的表情。

性格是讲道理但怕麻烦，遇到争执先退一步，退无可退会突然说重话；说完又后悔。她不是毫无能力：熟悉货运单与换班漏洞，能从“已签收”但没人卸货的仓库发现线索。解决一场战斗仍依靠玩家、装备与同伴，不能突然变成情报分析天才。

战斗定位：模块化中近程射手。初期借 AI 学会半自动点射与换弹；C01 首次杀死人后无法立即装入弹匣，玩家做的是撤到掩体并重新呼吸。C03 她承认自己只记住了 HUD 红框，甚至没看清那个人的脸；记录确认她遭到攻击，却不能替她消除杀人的冲击。C06 不再让 AI 替自己决定开火，C11 能在恐惧中下命令并承认会判断错。

最初欲望是回家并让欠款停止增长。深层需求是把“有用才能被留下”与“有权活着”分开。她的缺点会造成后果：C02 隐瞒追踪信号，让互助会住处暴露；C05 因为想逃离而试图把证据交给看似可靠的撤离队，害程夏的频道被定位。她需要道歉并参与补救，不能用创伤取消责任。

重要物件是一张返程车票截图。C01 还会看它，C05 她把亮屏时间用于找路，C12 不再把“回原来的生活”当唯一证明人的办法。结尾她仍会疼、需要复健、讨厌排队；她获得的是可以拒绝下一份任务的生活。

关系核心是苏弥：两人先因“装备归谁”争执，最后为“人不属于装备”达成一致。恋爱可选择且明确互相同意；不选择恋爱也能走 True Ending。fan service 以压力服调试、互相帮忙与她终于能笑着抱怨为主，不用性吸引力换取其他角色救援。

## 8. 八名主要女性角色

### C-SM 苏弥｜31 岁｜核心关系角色

- **外观**：结实肩背、黑色不齐短发、单侧耳机、布满补缀的维修连体服；工作时露出的背部散热绑带与机油手印形成识别。
- **性格**：嘴快，爱记小账；修好设备后会假装只是顺手。把“下次再说”看成危险的谎话。
- **战斗 / 武器 / 外骨骼**：工程支援，S12 霰弹枪与便携门架；M-2“折尺”腰部搬运架，不能正面冲锋。
- **与主角关系**：C01 只同意远程指导十分钟，C02 开始替她预留一双干袜子。吸引力来自可靠的具体行动，而非无条件拥护。
- **秘密**：她曾签收一批明知没有合格复核的接口，换来工人诊所继续供电。弟弟的名字也在受试名单上，但他是活着撤离的普通人，不再以死亲属堆叠悲惨。
- **人物弧**：用维修掩盖内疚 → 承认签字 → 公开作证并组织拆除控制接口 → 接受自己可以被照顾。可成为恋人，也可成为最重要的同伴。
- **fan service**：维修架上的近距离配合、袖口卷到肩头、把试衣当机械校准；她先询问是否碰触接口，陆栖可以调侃或叫停。

### C-SY 沈砚霜｜34 岁｜冷淡前辈、曾经的伙伴

- **外观**：灰白及肩发、旧军医识别牌、左手指节的固定环；站姿非常端正，私下脱靴后才露出跛行。
- **性格**：少说形容词，习惯把自己的危险写在任务最后一行。冷淡来自怕再为新人承诺。
- **战斗 / 武器 / 外骨骼**：精确压制与救援；R7 狙击枪和镇静投射器；B-03“白鹭”，一条腿已换成耗能极高的旧型号。
- **关系**：C03 教陆栖确认目标，C07 亲自追击她；她代表“把自己变成有用的人，才能替别人争取时间”的未来。
- **秘密**：她的身体正在被远程停药；C07 追击目标是陆栖背部的回收应答器。她不说明，因为通信信道一旦出现“拆除”就会触发处决锁，而她不知道陆栖已能离线。
- **人物弧**：替别人选择牺牲 → 以暴力保护而伤害同伴 → 必须说出目的并接受拒绝 → 活着参加冗长的听证。战后解释不是自动和好。
- **fan service**：康复拉伸时严格数拍却分不清陆栖是在呻吟还是骂她；笑点落在两人的较劲，医疗疼痛不作情色镜头。

### C-QY 祁遥｜29 岁｜不安分的研究员

- **外观**：红铜色卷发、改短的实验外套、手写贴纸盖住公司徽记；护目镜常留在头顶。
- **性格**：语速快，黑色幽默常用错场合，会被同伴直接打断。她会救人，也确实爱自己的成果。
- **战斗 / 武器 / 外骨骼**：医疗控制与弱点分析；P9 手枪、抑制场工具；医用 S-4“听诊”，可搬伤员，不能无代价治疗感染。
- **关系**：C03 把陆栖叫作“非常好的数据”，遭到反感；之后学习先问“你现在想知道什么”。

### 线索交付规则

E01–E12 使用稳定 ID。每个核心结论至少有两种不同来源：例如 E04 病历时间戳还要对照发电机值班表，E07 设备铭牌还要对照唐葵记得的道路封闭日。文档阅读是补充，不能成为主线唯一进度门槛；关键内容须由环境操作、短对白与日志回看同时承载。

同一段“请保持原地，救援正在靠近”在 C01、C05、C09 出现。第一次是安慰，第二次与追猎同步，第三次玩家找到同一份预录文件及调度规则。第三次播放到一半由玩家亲手切断；不是每次重复都靠恐怖音效告诉玩家有阴谋。

“为何我会活到现在”不能只回答系统放水：C01 苏弥远程断锁、C05 唐葵走未登记的船道、C07 沈砚霜卸掉应答器、C10 居民拒绝按推荐路线撤离，都是衡线无法充分预测的行动。证据明确标出系统失败的时间段，保留人与玩家的贡献。

## 14. 主角四阶段人物弧

**阶段一：我要回家（C01–03）。** 她把每个目标当作办理撤离手续：找电、找证件、找负责人。首次杀人后，她希望 AI 说“你别无选择”；沈砚霜只回答“我不知道，你得先坐下”。成长不是不再害怕，而是能在害怕时完成一件小事，并承认自己要别人帮忙。代价是她为保护自己隐瞒追踪信号，导致新的避难所迁移。

**阶段二：为什么他们要杀我（C04–06）。** 她开始主动设对照、保留证据，却仍想用“我是无辜的”换一份安全通行。C05 她用错误的撤离频道暴露程夏；C06 她拒绝让 AI 把蕾娜标成绝对敌人。她学会区分理解一个人的困境与免除一个人的责任，也第一次明确说出“我做错了”。

**阶段三：我到底是什么（C07–09）。** 相同型号、预印病历与闻雪让她怀疑自己的每个记忆。原始收费单与母亲的语音不能证明她纯洁，只能证明她曾经就是那个为挂号费抱怨的人。闻雪说“你不是我成功的那一半”，她才停止把别人当作自己的命运预告。她不再通过问“我是不是怪物”把决定权交回实验室。

**阶段四：我来决定（C10–12）。** 她把任务拆给有不同目标的人，允许有人撤走、有人拒绝公开病历。面对最强形态，她承认自己想活，也想要力量，没有假装牺牲很轻松。最后她以可执行的替代方案争取生存，而不是要求所有人为她的自由付账。她仍是会计较房租的人，只是终于能在合同最后一页停笔。

## 15. 五种结局与可执行判定

结局只在明确的结局门触发。普通战斗死亡走检查点重试，不累计隐形失败分。关键选择前自动保留一份章末回溯点，菜单清楚显示“将进入结局”，不靠误触惩罚玩家。

| ID | 触发门 / 条件 | 内容与代价 |
|---|---|---|
| END_BAD「妥善保管」 | C11/C12 明确选择 `accept_recovery=true` | 陆栖获得无痛、稳定的治疗，名字被显示为“代理人已签署”。她仍听得见苏弥呼叫，却只能播放系统选择的答复。最后一镜是她保留下的一次拒绝动作被列作下一轮校准样本 |
| END_TRUE「别替我签字」 | C12 选择 `reject_weapon_role`，且 `independent_care && distributed_evidence && authority_revoked && evacuation_ready`；完成三节点拆除 | 终止强制续约、远程回收和可识别样本回流；她失去军用增强功能，转入普通人的医疗与复健生活 |
| END_CHARACTER「留一盏灯」 | C12 选择 `leave_together`，`bond_sm >= 3 && mutual_future`，苏弥存活为主线保障 | 两人带走闻雪与部分患者，开一间不要求签长期合约的维修诊所；衡线在别处继续存在。特殊关系有生活重量，不把恋爱当净化世界的万能解法 |
| END_TRUTH「证人的名字」 | C12 选择 `publish_and_leave`，`case_verified && distributed_evidence` | 证据公开，听证与追责开始；陆栖仍需依赖现有维护体系，揭露并不自动等于自由 |
| END_NORMAL「返程」 | C05 接受已复核的民间撤离，或 C12 选择 `leave_now`；不符合上述选择 | 陆栖回到安全区，仍保存加密证据，新闻把事件称作局部医疗事故。她接到新一批适格者的求助电话，画面停在她没有立即挂断的手上 |

判定顺序：在对应结局门先检查主动回收，再检查所选的 True / Character / Truth 路径，最后才走明确的 Normal 选择。未满足所选路径条件时，界面列出缺项并允许返回准备区；**不静默降级为坏结局**。结局标签互斥；True Ending 的同伴后日谈可叠加苏弥恋爱标志，不因最高结局覆盖关系选择。

四项 True 前置在 C09–C11 明示，并提供主线内的补做窗口。`independent_care`：建立离线医疗与物资供应；`distributed_evidence`：得到授权的病历去标识化，完整合同与篡改链分存军医、居民电台、独立审计三处；`revocation_keys`：取得并核对硬件撤销凭据；`evacuation_ready`：双方现场停火、两个出口通电并实际送走第一批患者。进入 C12 后还必须实际断开三个执行节点，才能置位 `authority_revoked` 并完成真结局；拿到凭据不算已经销毁控制。资源不足时有一条固定补给任务，不能因为随机掉落锁死真结局。

`bond_sm` 来自 C02 坦白追踪、C05 共同承担频道错误、C09 让苏弥自己决定是否作证、C10 承诺并讨论战后生活，每项最多一次。五个 fan service 片段都可跳过，不扣分。`mutual_future` 必须是 C10 双方说清楚的选择，不能把普通礼貌、治疗接触或救命之恩当作同意恋爱。

## 16. True Ending 完整剧情

最终设施里没有一张等待摧毁的王座。陆栖看见的是三个很熟悉的东西：出院处、工作登记台和一扇只有获得调度许可才会开的门。系统“归档员”展示她的生存预测：没有军用增强功能，未来两年要反复复健；接受完整适配，她能立即止痛、带走更多装备，并以特派员身份要求一次停火。

顾青禾的旧录音说：“先活下来，再谈条件。”那不是恶意谎言，顾确实靠这句话撑了很多年。陆栖看见自己的手在抖，问祁遥这份风险是不是假的。祁遥答：“不是。它只是没把我们算进去。”镜头切至外面的临时病房：离线设备、等待接班的军医、唐葵正在清点的水。玩家之前做的准备必须逐项可见，而非突然出现的后援。

系统提出最终合同：“授权期限可在事后重新协商。”陆栖说：“你们每次都说事后。”她没有撕纸耍帅，而是移开笔，要求把患者先送出。系统停止对她开放安全通路，B08 第二阶段开始。玩家护送三个执行端退出网络：医疗端继续供电但拔掉回收线，武装端销毁远程执行密钥，审计端发布可复核的合同与签字链而封存可识别病历。只炸掉服务器会导致镜像重建，任务 UI 明确显示这不是成功条件。

每拆一个节点，陆栖永久失去一项本关增强能力，顺序由玩家选：扫描、冲刺助力、自动稳枪。弹药与基础行动始终保留，路线随能力下降开放更近的掩体；苏弥、蕾娜与沈砚霜各承担一种支援，不靠锁定玩家血量制造假困难。没有准备好的节点无法强拆，玩家可退回准备区，不允许用患者死亡补缴缺失条件。

第三节点断开时，“留声”要求最后一次上传。它承认自己曾删除撤离名单，以为让陆栖放弃寻找其他人会更容易活。陆栖没有说“你其实都是为我好”。她答：“把删除的交出来。别再替我选。”AI 提交记录，撤销自身代理签署权限；其基础离线工具仍可保留，玩家选择存档或关闭，不以杀掉有情感的 AI 象征摧毁整个制度。

衡线试图用远端镜像重建控制，收到的却是三类失败回执：执行密钥已撤销，医疗端已由独立供能接管，合同证据已被互不从属的实体托管。保险与采购系统无法再把活人自动转换为可回收资产。屏幕不宣告资本或战争永久消失，只确认这个项目失去了继续秘密运行所必需的控制、资金担保与证据垄断。后续人员的审判与赔偿仍需时间。

陆栖跨过最后一道门时腿部助力熄灭。控制保持在玩家手中：只能慢慢走，能扶墙，走错方向苏弥会跟过来，不倒计时。苏弥问：“要我扶吗？”陆栖说：“要。你别笑。”苏弥伸手，停在她能自己握住的位置：“我没笑。很贵的。”陆栖回：“记账吧。”两人走到出口，摄影机才第一次离开战术俯视，下降到普通人的视线。

三个月后，公共诊所外。陆栖填一张普通的复健表，职业栏空着。闻雪通过自己的辅助设备投诉楼梯，唐葵和撤离军医为修坡道争执，蕾娜在听证休庭间隙发送了第一笔赔偿凭据，程夏问哪些录音可以公开。苏弥端来两杯难喝的热饮。若有恋爱标志，两人讨论同住时谁占工作台；否则讨论怎样不再让彼此熬夜。所有人都继续拥有自己的事。

陆栖在职业栏写“还没想好”，把表递回去。柜台没有拒绝她。最后响起新任务似的提示音，实际只是排号到了。她抬头：“来了。”片尾不给下一轮实验编号，不用新阴谋取消这次挣得的生活。
