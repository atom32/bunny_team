# 12. 关键演出场景

这些是待制作的演出设计。事件 ID 与章节、角色、线索保持一致。所有人物使用艺术家制作的角色、表情与动作资源。对白以中文为母版，语音可晚于字幕接入；不能在配音尚缺时让主线无法推进。

共同实现规则：进入演出前清除尚未处理的攻击输入、保存回滚点；镜头锁定期间暂停附近 AI、投射物、状态伤害与关卡计时。长按跳过只执行一次最终状态提交，关键证据进入日志。退出时恢复原相机、输入与辅助功能设置。持续移动的无线电段不锁镜头；对白字幕不得覆盖准星、Boss 弱点或交互提示。

## K01 箱子里面｜C01 / S01｜32 秒

**触发**：新章开场；**镜头**：黑屏中的运输噪声 → 舱内手持终端特写 → 肩后窄视角；只用一个舱体内景与三个机位。陆栖按工资短信中的数额算了一遍，听见撞击后抓住固定带。画外工作人员：“到了以后别直接站起来，先等——”音频被截断。她醒来问：“我迟到了？”AI 回答：“您的到岗状态已更新。”

前 20 秒锁移动，终端出现后允许玩家自行关闭，镜头过渡到俯视并归还完整控制。提交 `c01_awake`，不授予任何战斗能力。跳过落点相同。

## K02 手指夹住了｜C01 / S05｜最长 38 秒

**触发**：第一名武装回收员在真实战斗中死亡；先清空该小区域的敌方攻击，不能叠加死亡判定。镜头不追子弹入体，只看陆栖试图重新装弹的双手、掉落药袋与她的脸。陆栖：“能叫救护车吗？”AI：“当前急救优先级——”苏弥打断：“先把手拿出来。你夹住了。”

保留慢行与转向，停火但不屏蔽暂停；玩家可走进旁边掩体触发最后一句，未移动时苏弥用路灯指示方向。专用动作三条：手抖、取出手指、靠墙呼吸。事件提交只记 `first_human_kill`，不奖励成就、分数或性感战损。

## K03 它听见什么｜C01 / S07｜8 秒

**触发**：必经的接口校准台启用；B01 预览体与玩家隔一道玻璃，不构成攻击目标。固定中景同时包含陆栖的接口灯与远处担架员，它停止敲门、把空担架推向灯下。陆栖：“它在看我。”AI 延迟半秒：“运动反应。无需记录。”

全程可移动，镜头只轻微拉远；不开恐怖特写。需要一条停顿与推担架动作。提交 E06 的观察前项 `signal_observed`，不能提前给出完整结论。

## K04 待回收｜C01 / S10｜30 秒

**触发**：Boss 击败且玩家持任务卡开启出站闸；门真正打开后再切镜头。屏幕先显示“待接收”，后端状态刷新成“待回收”。一架搜索机越过门框，红光停在她鞋边。广播念编号；陆栖看向返程车票，屏幕因电量低熄灭。

前 12 秒锁控制，随后恢复慢行让玩家走过门。苏弥：“往有水塔的地方走。”提交本章结果与下一章入口后切黑，不能在门仍上锁时提交成功。

## K05 水不是给你的｜C02｜24 秒

**触发**：回收车抵达营地，且玩家已将一个水箱搬到出入口。俯视中景，居民把水递给陆栖，她伸手时对方指了指她身后的净水机。唐葵问：“它们为什么跟着你？”陆栖承认信号未关。唐葵不打她，也不原谅：“那就一起搬。先别道歉。”

镜头始终可转，搬运目标恢复后对白停止；需要三名有名字的居民动作循环，禁止无限群众人海。提交 `camp_relocated`，记录是否主动坦白供后续关系对白选择。

## K06 杯子放桌上｜C03｜42 秒

**触发**：患者转运结束。值班室同一张桌子的正反打；陆栖端杯子的手抖到水溢出，沈砚霜把杯子放下。陆栖：“你第一次……是不是也这样？”沈：“我记得那个人的鞋。别的说不清了。”沉默两秒后她递来干布。

锁移动但允许选择“我想一个人待会 / 陪我坐会儿”，双方都尊重选择，不计隐藏好感。可重复使用坐、擦桌、推杯三种动作；没有自动治愈创伤的拥抱。提交 `first_kill_discussed`。

## K07 对照开关｜C04｜20 秒，可操作

**触发**：玩家连接观察室两条电路。相机保持游戏视角，画中画只显示感染者的手与状态灯。玩家亲手开、关、再开信号，观察可复现反应。祁遥：“看，稳定了。”陆栖：“你说的是它，还是我？”

不锁操作、不用假按钮；切断实验设备后立即停止额外伤害。需要三种状态机动作而非整段影片。E06 仅在完成两次对照且取走日志时提交；离开后可重来，禁止无意误操作杀死关键证人。

## K08 寻人屏｜C05｜18 秒

**触发**：幸存者离开商场中庭，玩家连接维修终端。广告里的模特冻结，屏幕逐行变成寻人名单。苏弥故作轻松：“这么大的屏，光卖鞋浪费了。”陆栖把程夏的呼号加到最后一行。

全过程可操作；只需屏幕 UI 动画、打字音与两条抬头动作。名单来自本章已登记 NPC，不生成虚构已救人数。提交 `mall_names_uploaded`，随后追猎警报打断日常感。

## K09 四个签名｜C06｜40 秒

**触发**：B04 缴械后；根据黑箱是否完整播放本地音频或打印摘要。镜头先看四个队员姓名，再看蕾娜修正合同里的“设备损耗”。陆栖：“你现在相信我了？”蕾娜：“我相信这个时间戳。你还得自己作证。”

锁 25 秒，之后允许玩家选择保管人；背包满不阻止关键证据入日志。蕾娜放下枪的动作必须与战场缴械状态一致。提交 `pmc_testimony_available`，不自动满好感。

## K10 她每一枪打向哪里｜C07｜35 秒

**触发**：B05 停战且回收应答器已断电。复用玩家刚经历的场景，不回放整场战斗；用最多三条半透明射线标出天线、电缆和锁扣。沈砚霜：“它下次接听，就不归你管了。”陆栖：“所以你替我决定？”沈停顿：“是。”

动画分支：通信模块已毁则她亲口解释，未毁由苏弥读记录、沈点头确认。最后玩家主动选择递药或让医疗队来；两者都能救人，关系语气不同。提交 `ally_motive_known`，保持受损模块外观直至维修。

## K11 不是成功的一半｜C08｜45 秒

**触发**：B06 外部回路安全、医护允许接近。对称镜头起初将两人放在两张床上，随后转到闻雪自己的视线。陆栖：“如果我早一点——”闻雪：“别把我放到你的过去里。我还在这里。”

陆栖把替她挑的衣服放回去，闻雪自己拿起另一件。镜头不审视她的损伤，重点是手伸向自己的选择。提交 `wx_personhood_acknowledged` 与患者转运状态；需要卧坐、挑衣、让位三条动作。

## K12 请勿讨论工作｜C09｜36 秒

**触发**：程夏获救，队伍进入无网食堂。大家以为声音来自远方，程夏从桌底拔下一截录音线，直接说：“现在可以骂我了。”苏弥先盯着墙上“请勿讨论工作”的告示，忍不住笑，笑完才说签收记录的事。

六人站位限制在一个长桌周围，镜头不轮流给所有人立绘。陆栖可选择先谈撤离或先听解释，只改对白顺序，证据都提交。用这场景把罪责、疲惫与荒诞放在一起，不用一位解说员讲完全部真相。

## K13 第三次广播｜C09｜14 秒

**触发**：播放器中找到同一份救援预录文件。前六秒复用 C01 原声与波形，随后出现调度条件与接收对象编号。玩家按下实际“断开播放”按钮，声音立即停止。程夏：“这次它说不完了。”

保留控制，按钮支持键鼠与手柄焦点。提交 `broadcast_origin_proven`，E02、E09 在日志中互相链接；跳过也停止声音，不允许切场景后继续播放。

## K14 水桶接力｜C10｜25 秒，可操作

**触发**：第一条民间船道开放。玩家仍在护送与警戒，镜头稍拉远，居民通过水桶接力把补给传上船。AI 报告推荐路线失败，唐葵回答：“我们又没去。”一名敌对方军医从对岸接过箱子，双方没有拥抱庆祝。

需要八名可复用的居民/医护模型与两条船路径，远景人数用已救名单计算。提交 E11 和第一批撤离完成；不把背景船设为玩家看不见的自动成功。

## K15 邀请不等于命令｜C11｜43 秒

**触发**：进入 B07 前安全区。顾青禾卸下肩甲展示旧接口，而不是展示身体伤口。她说：“你能把它做得比我好。”陆栖问：“如果我不想接你的班呢？”顾：“总要有人。”镜头留在陆栖脸上，让沉默成立。

明确弹出“继续听报价 / 拒绝接管”，前者仍不立即触发坏结局；只有二次清晰选择交还控制权才进入 END_BAD。拒绝后相机先回到战术位，再恢复攻击，不让玩家在过场中挨第一枪。

## K16 先让他们出院｜C12｜38 秒

**触发**：四项 True 准备齐全且玩家选择拒绝武器身份。镜头交叉显示合同、临时病房、三处托管回执，均读取实际准备状态。祁遥确认失去强化后的医疗风险。陆栖：“我很想活。你们不能每次都拿这个问我。”她把笔放下，先要求患者离开。

三条外部画面各不超过四秒，可用已存在场景机位。提交 `reject_weapon_role` 后开启可操作的三节点目标；不要在演出中替玩家自动拆除。

## K17 要我扶吗｜C12 / True｜40–90 秒，长度由玩家决定

**触发**：三节点完成、最后患者撤出。恢复近距离第三人称镜头与慢行控制，苏弥走在半步之外。玩家可扶墙，苏弥问是否帮忙；按交互键才握手。对白为：“要。你别笑。”“很贵的。”“记账吧。”

没有倒计时、屏幕淡出掩盖失败或必须成功的 QTE。可开启辅助自动走路。至少两条步行速度与牵手对齐动画，兼容不选择恋爱。走过出口触发结局提交。

## K18 排号到了｜True 后日谈｜65 秒

**触发**：END_TRUE 提交完成。白天诊所，三个固定机位；陆栖的职业栏写“还没想好”。闻雪投诉楼梯，唐葵争论坡道，程夏询问公开录音的范围。关系标志只切换苏弥关于同住或互相休息的两句对白，不替换整个结尾。

最后提示音像任务通知，实际是排号；陆栖抬头：“来了。”提交片尾成就和可回放章节目录，不能在这一刻续签下一轮实验。需要诊所小场景、五条生活动作与表格 UI，没有战斗特效成本。

# 13. 五个有记忆点的 Fan Service 场景

共同节奏是战斗结束、伤害停止、设备处理、短暂恢复正常生活。每场从角色的选择开始，可完整跳过，不发装备优势或关系分；相关主线信息另有独立入口。衣服损坏只影响修补与造型，不设伤害越重裸露越多的奖励规则。

## FS01 两只手借我｜C02，苏弥与陆栖，70 秒

**自然动机**：接口散热背板被泥堵住，维修需要陆栖按住支撑杆并抬起手臂。她穿完整压力服，脱下的是外层支架。镜头从背部接头移到两人的手和表情，近距离来自真实工作空间。

苏弥先问能否碰接口，陆栖说：“可以，你别像在拆快递。”苏弥：“快递一般不会催。”扣件弹开时她们同时后退，随后相视笑出声。陆栖最后主动替苏弥擦掉额角机油，苏弥停半拍才说“那是散热膏”。

**关系 / 记忆点**：第一次把修理从交易变成互相照顾；“两只手借我”后来在 True 离场成为被主动请求的帮助。需要维修台、肩后和面部两机位、四个上身动作。选择不靠近则苏弥递工具，仍能修好设备。

## FS02 前辈也数错拍｜C03，沈砚霜与陆栖，55 秒

**自然动机**：医院值班间的例行卸载与拉伸。角色换成训练背心和长裤，鞋靴摆成一排。沈砚霜认真数拍，陆栖发现她会漏掉七。

陆栖：“你跳过七了。”沈：“那就多做一次。”“这不是一样吗？”沈终于笑，随即承认自己小时候练操就会漏拍。镜头看并排的动作、肩背张力和她罕见的表情，不特写疼痛或私密部位。

**关系 / 记忆点**：冷淡前辈第一次显得不完全可靠却更亲近。C07 战后沈数药片时又漏七，陆栖接上，成为共同记忆。需要两套短拉伸循环与一条笑容表情；可选择只坐旁边聊天，无好感惩罚。

## FS03 全城最后一家更衣室｜C05，陆栖、苏弥、唐葵，90 秒

**自然动机**：湿透的外层服装需要晾干，商场员工更衣室有独立发电和未开封的工作服。门与帘子真正关闭，换衣过程通过衣物递接、鞋子和影子表达，不偷窥。

唐葵挑走最夸张的促销外套，苏弥把围裙反穿来装工具。陆栖在镜子前试一件普通衬衫，问大家是不是很奇怪。苏弥答：“像下班了。”短暂静默后，她们把残留促销音乐调大了一格。

**关系 / 记忆点**：玩家看见角色可以拥有职业与战斗之外的造型。门外传来追猎警报时，陆栖把衬衫认真折好放进包，不是立刻丢掉日常愿望。需要原创三套便装、帘子、镜面替代机位；无需真实实时反射。服装选择全部纯外观，跳过默认用同样完整的便装组合。

## FS04 被子里只够两个人｜C08，闻雪与陆栖，65 秒

**自然动机**：转运停靠点温度低，共用一条加热毯降低耗电。闻雪自己邀请陆栖过来，先把杯子挪出空间。镜头以半身双人构图表现靠近和热气，不暴露治疗过程。

闻雪：“你是不是很怕碰坏我？”陆栖回答可以承认担心，也可以说自己更怕烫水；闻雪伸手调节毯子：“我会说的。”她们轮流吐槽同款终端的客服电话，终于笑到咳嗽，又互相递水。

**关系 / 记忆点**：闻雪得到决定距离的权利，也不再只作为失败样本出现。陆栖学会问与等答复。需要毛毯完整包覆、坐姿与递杯动作；不把照护需求当情色依赖。可不靠近，改为坐对面聊天，剧情含义成立。

## FS05 临时海滩，禁止度假｜C10，陆栖与苏弥，80 秒

**自然动机**：城市外侧潮汐台阶暂时安全，她们用余下的清水洗去外层泥污，晾干装备。战斗压力已经解除，角色穿短袖便装或完整运动内搭。背景是仍在工作的渡船，度假幻想带一点荒诞。

苏弥在潮位牌下划出一小块“休息区”，陆栖问能不能租躺椅。苏弥用工具箱当脚凳，回答“豪华套房，别碰扳手”。这里可以延伸 C10 的明确关系选择：谈共同生活、选择同伴或暂不决定；不靠镜头暗示代替口头同意。

**关系 / 记忆点**：两人在垃圾桶旁认真想象一个普通假期。苏弥把一颗平整石头留作“房卡”，后日谈可摆在诊所窗台。需要既有码头台阶、清洗上身动作、两套坐姿和夕照；不另造海滩大地图。跳过片段后仍可在营地单独进行关系选择，避免把恋爱锁在 fan service 观看时长后面。
