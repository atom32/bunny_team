# 17. 第一章《签收失败》完整生产剧本

版本 1.0｜预计首玩 25–30 分钟｜场景 C01 港北运输站｜人物全部成年

这是可交给关卡、演出、程序、音频与本地化团队拆任务的设计稿，尚未接入当前 demo。动作提示一律通过 InputMap 对应动作解析，不把某一套键位写死到字幕。台词 ID 永久稳定，修改文本不能改变存档引用。

## 关卡与运行约定

路线：A 运输舱 → B 卸货道 → C 安检棚 → D 维修通廊 → E 医疗转运棚 → F 出站闸门。回溯不超过一个区域；关键物品写入任务状态，不占普通背包格。

首次枪械为 P9，9mm，初始一匣与两匣备用；此数值是灰盒起点，正式难度需调试。后续剧情逐渐开放其余武器，独立 demo 的七枪试用功能保留为原型测试入口，两者不是同一进度系统。教程补给仅在未完成相应教学且弹药不足时补到下限，不允许往返刷成永久仓库资源。

检查点 CP01 开场醒来；CP02 舱门打开；CP03 进入安检棚前；CP04 第一次杀人演出完成；CP05 Boss 前补给；CP06 Boss 后；CP07 章节提交。死亡恢复检查点时恢复该点敌人、道具、门、弹药、模块状态与剧情状态，不能保留失败尝试掉落的战利品。

| 状态 | 写入时机 | 后续用途 |
|---|---|---|
| `c01_awake` | S01 控制权交还 | 禁止重复播放撞击 |

## S09：空担架

**触发**：B01 实际 Defeated，伤害与召唤都已停止。**目标时长**：演出 15 秒，探索 1–2 分钟。
