# 10. 十二章完整剧情

与 [故事设定](NEON_BASTION_STORY_BIBLE.md) 共用角色与线索 ID。目标流程约 7–9 小时，章节 25–50 分钟，另有可跳过的营地交流。以下是开发设计，当前 demo 没有实现这些地图、任务、感染者或 Boss。所有未来人型 NPC、感染者及角色尸体必须使用有来源的艺术家模型、蒙皮与动作；不得用几何拼装替代。

每章使用一个可回访的准备点、两至三个战斗空间和一个收束空间。长篇解释拆进撤离准备、环境操作与短演出；单次不可操作镜头原则上不超过 45 秒。

## C01《签收失败》

**地图 / 时间**：港北运输站，夜，暴雨刚停；运输舱 → 破损卸货道 → 医疗转运棚 → 闸门。目标 25–30 分钟。

**战斗目标**：恢复舱门供电，拿到手枪与维修件，避开扫描无人机，穿过转运棚并击败 B01。新敌人是踉跄感染者、武装回收员与无武装扫描机；不在第一分钟塞入完整兵种表。

**剧情推进**：陆栖先检查工资到账短信，才发现隔壁运输单元没有回应。“留声”指导她找补给，苏弥通过维修频段教她断开反锁。第一名回收员命令她把手离开枪，通信中却有人要求“接触后终止”；战斗中她第一次杀人。她发现对方的药袋与工作证，手一直抖，想拨急救电话却被告知优先级不足。苏弥让她做一件具体的事：先把夹住的手指从弹匣底部拿开。

**新角色 / 线索**：陆栖、苏弥、“留声”正式进入；程夏只有一句被删掉的无线电。E01 补给柜精确匹配她的编号、尺寸与返程班次。B01 在她校准接口时停住片刻，随后又被广播激怒。

**Boss / 记忆点**：B01 担架员；玩家拆掉背部信号箱后，它仍下意识拖动一副空担架。结尾陆栖终于打开自称安全的闸门，屏幕把她从“待接收”改为“待回收”。

**解决 / 新问题 / Cliffhanger**：她能离开舱体，知道这不是一次普通坠机；仍不知道为何医院设备早就认识她。无线电清晰播出自己的编号：“该目标不得随撤离人员离境。”她问苏弥：“你刚才说十分钟……现在呢？”黑屏前苏弥答：“往有水塔的地方走。”

## C02《不在救援名单上》

**地图 / 时间**：战区旧城、水塔街与防疫检查口，黎明。主路可打通，住户楼梯提供代价较低的绕行。

**战斗目标**：帮唐葵取回净水车电池，夺取可用步枪与弹药，穿越 B02 封锁区。新敌人是配盾的回收员、催离无人车；感染者会被喇叭声引向战场，形成交叉威胁。

**剧情推进**：唐葵先问她能否搬水，后来才问名字。陆栖怕被赶走，隐瞒设备仍在发出识别信号。无人车抵达临时营地，迫使居民迁移；她必须亲自搬走备用水箱，不能靠选择一句好听对白解决后果。苏弥在小修理铺首次露面，认出她身上尚未安装完的回收模块。

**新角色 / 线索**：唐葵与蕾娜首次露面，苏弥实体登场。E02 是从车载记录恢复的删改命令，E03 是蕾娜按编号而非姓名索敌的无线电。蕾娜准许普通居民离开，只拦陆栖，使她第一次确认追猎具有选择性。

**Boss / 记忆点**：B02 封街车。破坏广播阵列会停止感染者被诱导聚集；保住净水车的支路会在 C10 回报一条居民撤离路。战后苏弥提供热水，只给她半杯：“另一半要洗接头。”

**解决 / 新问题 / Cliffhanger**：明确她被主动追捕，所谓“污染源”名单并不等于实际感染。苏弥读出模块上的医院转诊编号，预约日期竟是灾难前十一天。陆栖决定先去医院问清楚，再离开。

## C03《提前十一天》

**地图 / 时间**：停电医院，上午；门诊大厅、备用电房、住院层、病历档案室。

**战斗目标**：连接病房电源，护送六名有姓名的患者通过一条短撤离线，取得病历副本。新敌人是循铃声行动的感染病患与隔离队；病患可避开或短时镇静，不能用“全楼清空”作为救援目标。

**剧情推进**：沈砚霜指挥一支已经失去上级联系的救护队。她教陆栖看敌人的手与射界，允许她躲在柜台后呕吐，但下一次换班仍要求她把哨位交代清楚。祁遥试图抽取样本，陆栖第一次拒绝一份看似例行的同意书。恢复电源时，打印机吐出写着她编号的旧标签，旁边还有几十个人。

**新角色 / 线索**：沈砚霜、祁遥。E04 病历时间与发电机签到表相互验证。主角回看第一次枪战记录：红框之前，那名回收员也在询问上级；这不取消她的自卫，只让她明白自己杀死的不是一张红色图标。

**Boss / 记忆点**：无独立 Boss，章节高潮是电梯失效后的分组护送；玩家决定先运药还是先运行动困难者，两条路线都可完成，改变后续对话与弹药压力。值班室里，沈砚霜把她端不稳的杯子放回桌面，没有拥抱或说“习惯就好”。

**解决 / 新问题 / Cliffhanger**：证明名单在事故前已存在，不是追责时临时拼凑。病历的材料批号与感染者体内取出的接口一致。祁遥说：“这不是你第一次用我们的东西。”陆栖想起几年前的一次普通门诊。

## C04《身体的收据》

**地图 / 时间**：医院下方旧研究楼，通风检修道、无菌室、样本库；白天可见天井，避免全章暗室。

**战斗目标**：取回原始招募与治疗记录，现场切换校准信号完成两次对照，关闭 B03 的供能。新敌人是依靠接口脉冲协同的增生群和封存样本的研究警卫。

**剧情推进**：陆栖怀疑自己的记忆由公司植入。祁遥被迫交出筛选程序，但拒绝承认这意味着伤害，因为许多人确实拿到了治疗。玩家同时找到第三方门诊收据和家属留下的缴费信息：她的过去是真的，被秘密使用的是那些记录。沈砚霜提醒她，不必证明自己“毫无改动”才有权拒绝。

**新角色 / 线索**：没有新增主要人物；白塔医生季衡作为单章证人出现，之后可通过医疗队获知近况。E05 交叉印证真实过去，E06 通过感染者对有、无信号的不同反应确认接口关联。

**Boss / 记忆点**：B03 闸门。玩家将一个安全观察窗的灯从冷白切到暖黄，里面的感染者恢复数秒曾经排队就诊的动作，随后重新失控。镜头不要求玩家盯着畸变身体。

**解决 / 新问题 / Cliffhanger**：解释兼容性与感染者反应；否定“主角是被制造的假人”。样本库外却有一条为失控者准备的专用出城道，维护记录写着“第二轮”。谁同意过第一轮？

## C05《购物中心仍在营业》

**地图 / 时间**：停业商业区与顶层巴士站，午后；明亮橱窗、室内中庭、服务走廊提供反差。

**战斗目标**：搜集离线滤芯、冷藏盒与撤离燃料，护送商场幸存者到巴士站。新敌人是追踪热源的猎蜂机与使用烟幕的 PMC 搜索组。此章第一次提供六类枪械的完整选择，不强迫用某一把。

**剧情推进**：角色在仓库更衣区获得短暂喘息。陆栖发现一个有官方凭证的撤离频道，擅自发送队伍路线。蕾娜按时抵达，程夏为切断定位暴露自己的中继站。唐葵用未登记的小艇接走众人，陆栖必须承认决定是自己作出的，不能推给 AI。

**新角色 / 线索**：程夏获得独立通讯头像与姓名，但尚未实体见面。相同的救援广播第二次出现，这次播放时搜索队正接近；它不再可信。支线可找回员工的家庭照片，证明商场曾是普通人的工作地点。

**Boss / 记忆点**：无新 Boss；三段掩护撤离替代又一次门前大怪。商业屏幕继续播放“欢迎下次光临”，苏弥把它切成临时寻人名单。

**解决 / 新问题 / Cliffhanger**：证明所谓官方撤离会交出适格者。唐葵提供经过复核的民间渡船：此处可明确选择 END_NORMAL，或留下救程夏。若继续，蕾娜发来交易：“你要她，我要我那四个人。”

## C06《谁签的字》

**地图 / 时间**：PMC 前进基地，傍晚；装卸场、拘留舱、车辆维护坪、合同服务器。

**战斗目标**：核实四名 PMC 队员去向，取回程夏转运记录，击破 B04 的追踪设备。新敌人是战术包抄双人组与携盾工程手；可通过切电、封门、破坏武器取得空间，不需杀净营地。

**剧情推进**：蕾娜在谈判中拒绝陆栖的一切辩解，直到黑箱揭露队员早已被调往样本库，合同方却持续承诺救援。她仍坚持抓捕陆栖，认为至少要完成一件确定的事；战斗迫使她面对这套逻辑已经没有终点。陆栖选择保留可复核的原始证据，而非仅留下对自己有利的一段。

**新角色 / 线索**：无新增主要人物；失联队员透过录音与名牌拥有身份。E09 的第一份合同附件出现，尚不足以说明全局。保留黑箱可让蕾娜在 C10 提供掩护；破坏黑箱只改变资源代价，不让真结局永久锁死，可在 C09 审计镜像补证。

**Boss / 记忆点**：B04 蕾娜。打掉护目扫描器后，她第一次只能叫陆栖的名字。战后她在死者申请栏写“未完成赔付”，不是“任务损失”。

**解决 / 新问题 / Cliffhanger**：玩家理解蕾娜在保护谁，也看清她必须承担的责任。程夏尚活着，目的地是灾难前已停运的地铁设施。离开时沈砚霜突然拔枪，第一发打中陆栖背后的天线。

## C07《不要接听》

**地图 / 时间**：地下地铁，夜；维修车库、站台、潮水倒灌的过轨口。

**战斗目标**：带药物穿越地铁，把即将触发的回收模块与身体断开，抵御 B05 的追击。新敌人是按信号脉冲锁定接口的猎索机；列车供电可供其充能，也可由玩家截断。

**剧情推进**：沈砚霜不回答质问，只要求陆栖停下。战斗中她持续射击外骨骼模块、切断门边电缆，避免直接打击人的头胸；玩家当时可以观察，却不知道原因。打掉她的通信模块后，她仍试图接近，直到陆栖亲手拔下回收应答器，沈才倒下解释自己已被远程控制停药。

**新角色 / 线索**：无新增主要角色；闻雪通过近距离接口说出一句“你也收到邀请了”。E07 是采样架铭牌、购置日期与老地铁工的证言。每条所谓逃生支路都连向相同采样区域。

**Boss / 记忆点**：B05 沈砚霜，前伙伴战。战后重播她的射线记录，显示每一发原本想破坏的设备；陆栖仍说：“下次先问我。”沈答：“如果有下次，我会。”

**解决 / 新问题 / Cliffhanger**：解释她为何开枪，解决眼前回收模块威胁；不立刻修复信任。玩家发现这些设施不是灾后临时搭建。出口医疗屏显示闻雪与陆栖的照片并排，标题“同批对照”。

## C08《另一张床》

**地图 / 时间**：隔离区与外接供能病房，次日清晨；居民楼改造的病房让实验靠近日常。

**战斗目标**：保护独立电源，切断 B06 的过载回路，将受困患者转移至离线病房。新敌人是追随中继信号的感染群与无人样本车，敌我识别不能只依赖 AI 红框。

**剧情推进**：闻雪在广播里模仿客服欢迎词，以为只要证明陆栖也会失败，自己的命运就有解释。系统借她的供能回路攻击转运队；她既在挣扎，也主动拒绝配合。陆栖必须拆掉设备而不把她当作一扇待清除的门。祁遥提出更省事的强制镇静，被玩家与闻雪同时要求说明后果。

**新角色 / 线索**：闻雪实体登场。E08 监控显示隔离观察区在灾难前完成封闭测试，里面还没有病人；闻雪的自愿书后来被复制成其他人的代理授权。

**Boss / 记忆点**：B06 闻雪与病房供能架。两人用同一款难用的终端核对自己写过的投诉，发现共同点并不是什么神秘基因。战后闻雪自己挑要带走的衣服。

**解决 / 新问题 / Cliffhanger**：否定“成功的我取代失败的她”。闻雪不是唯一前代；系统已经预备另一批运输单元。程夏的中继终于恢复：“他们测的从来不是谁最会打枪。”

## C09《观察者也要下班》

**地图 / 时间**：生物研究中心的后勤与审计楼，白天；食堂、消毒廊、无窗档案室、普通员工出口。

**战斗目标**：救出程夏、封存两份相互矛盾的数据库、护送值班医生与数据载体离开。新敌人是擦除证据的审计保安与受远端控制的维修平台；后者仍可通过断网停机。

**剧情推进**：程夏承认自己曾把幸存者导向便于观察的路径。苏弥听到自己的签收记录被念出，无法再把责任藏在“设备只是工具”里。陆栖不会替她们统一说情，而是要求每个人自行决定是否作证。众人第一次在不经过 AI 的小房间里讨论接下来要做什么。

**新角色 / 线索**：程夏实体登场；没有新增主角团成员。E09 合同拼合完成，E10 首次露出目标指标“获救后续约概率”。E02 中的广播在这里找到预录原件与派发规则。主线界面开放四项终局准备，逐项说明用途与缺口。

**Boss / 记忆点**：无独立 Boss。烧毁档案的倒计时可以通过断开自动销毁电源暂停，给玩家选择保护隐私的时间。员工食堂仍贴着“请勿讨论工作”，角色因此短暂笑出声。

**解决 / 新问题 / Cliffhanger**：证明研究规模超过一个生化实验室，也解释重复广播。所有人的善意并非假的，但系统利用了善意制造依赖。顾青禾在公开频道宣布全城进入最终封锁，并点名邀请陆栖接管“定海”。

## C10《不按推荐路线走》

**地图 / 时间**：城市核心区的两岸接驳桥，黄昏；医院出口、居民码头、变电站共享既有场景模块。

**战斗目标**：维护两条撤离路、建立离线医疗、护送三处证据托管。新敌人是把补给箱伪装成救援设施的采样哨，以及双方不愿停火的强硬派小队。目标是清空射界与撤离人群，不是屠尽两支军队。

**剧情推进**：陆栖第一次分派任务，同时允许蕾娜先带走伤员、闻雪拒绝公开私人病史。各方愿意协作有明确交换：军医得到独立供电，居民获得名单副本，PMC 得到可追责的证据。唐葵不用系统推荐的大桥而组织小艇，观测模型连续预测失败。苏弥与陆栖在等待供电的间隙谈战后生活，可明确选择恋爱或同伴关系。

**新角色 / 线索**：无新增主要人物；两岸现场军官以短通话确认有限停火。E11 是预测误差与实际船只名单，对应 T5 的反证：人确实在做系统未安排的事。

**Boss / 记忆点**：无新 Boss，三波护送压力按道路状态生成；不是无尽刷怪。不同支线决定援助方法，至少保留可完成的基础方案。红色激光封锁线下，普通人递着水桶登船。

**解决 / 新问题 / Cliffhanger**：回答“救她的人是否全是假棋子”；同时证明离开控制体系需要真实替代资源。四项准备可补做。顾青禾取消一次炮击，为陆栖打开军营门：“我让你看看拒绝的价钱。”

## C11《最可靠的人》

**地图 / 时间**：军事基地的指挥训练场，夜；室外防护墙、指挥平台与手动控制室。

**战斗目标**：打断 B07 的远程火力指挥，取得执行权限撤销凭据，为最终设施维持通道。新敌人是与指挥链同步的重装适格护卫；破坏指挥节点会让其失去同步，而非全部自动死亡。

**剧情推进**：顾青禾让陆栖看见自己多年维持的救援记录，然后让她看见没有维护协议时自己的身体会怎样。她的邀请有真实诱惑：“你能比我做得更好。”陆栖可以明确接受回收，进入 END_BAD；选择继续则进入战斗。顾试图用“你也会牺牲别人”击溃她，陆栖回答自己无法保证零错误，但不会再要求别人永远放弃拒绝权。

**新角色 / 线索**：顾青禾实体主场，无新主角团成员。E10 的最终签批与 E12 的完整适配报价交叉印证实验目的。B07 的驾驶记录显示所谓完美适配依靠持续的行为限制。

**Boss / 记忆点**：B07 顾青禾。玩家拆掉肩部指挥器后，她第一次必须亲口请求部队停火；是否保留驾驶舱决定是活着交权还是在设备崩溃后由医疗队抢救，后续均须追责。

**解决 / 新问题 / Cliffhanger**：明确“成为最强兵器”的具体收益与条件，取得撤销权限，不再只有道德口号。最终门开启后，系统不称陆栖敌人，而说：“欢迎续约。请确认您本人在场。”

## C12《本人拒绝》

**地图 / 时间**：最终实验设施，黎明；医疗维持端、武装执行端、审计托管端、普通员工出口。

**战斗目标**：对抗 B08 的回收调度，保护已经独立运行的医疗端，撤销三处执行节点并护送最后一批患者。没有靠重新刷更厚生命值的超级怪物收尾。

**剧情推进**：系统提供稳定治疗与最强适配，要求的只是继续担任实验变量。陆栖可以选择回收、撤离、公开后撤离、与苏弥共同离开，或在条件完整时拆毁控制体系。每条路径显示代价与未完成的事，主角不因玩家选了较短路线就突然被写成懦夫。

**新角色 / 线索**：归档员作为 B08 的分布式界面出现；它没有新女性肉身。E12 成为可操作的续约条款。最后线索是“留声”承认删去的消息，并把未改写的记录交给她。

**Boss / 记忆点**：B08 回收室。True 路径每断一端失去一种增强能力，玩家最后亲自慢慢走出门；其他路径各有完整落幕，不共用一段爆炸后换字幕。

**解决 / 结尾**：回答实验测什么、哪些救援被操纵、主角为何适配，以及如何真正阻断下一轮。真结局取消强制续约机制并建立替代保障，不宣称世界从此没有战争；片尾是她在普通诊所排号，而非下一轮实验的预告。

# 11. 八个 Boss：部位破坏、战术与演出

Boss 的“部位”均为可读的装备或异常组织节点。UI 不把人体私密部位标作奖励目标。主角的装备战损沿用故事设定中的可恢复规则。下表为设计参数，伤害数值须在战斗原型里调试；没有伪称已平衡。

## B01 担架员｜C01｜感染强化体

转运员与损坏的搬运支架相连，仍试图把倒下的人送往广播声源。第一阶段有前方挥击与直线搬运冲撞，地面足迹提前提示；无追踪必杀。

可破坏背部信号箱与两侧助力轮。破坏信号箱取消声源召唤、打开背部停滞窗口；破坏单侧轮让冲撞转成有偏角的扇形，可撞开玩家身后的维修栅栏。核心倒地前镜头根据破坏项显示停转轮或被拔下的广播线。击倒后它轻推空担架的动作在两种路径都保留。初战只要求打掉一个外部模块，不要求新手精确拆完整套。

## B02 封街车｜C02｜无人防疫平台

身份是本应用于疏散广播的市政车辆。先用盾板封街、喇叭聚集感染者，再部署催离弹迫使玩家换掩体。其“保护平民”模式只识别已登记人员。

顶置广播阵列破坏后停止引来感染者；前盾液压臂破坏后盾板落地成为玩家掩体；定位桅杆破坏后失去追踪弹，只能朝最后位置射击。击败演出中，保留广播会继续机械地道歉，先拆广播则只剩液压漏气。平民撤离路线随落盾方向开放，不用另一场过场代替真实场地变化。

## B03 闸门｜C04｜生化实验体

由实验设施的稳定装置与增生组织形成的固定生物门，既不必长成人脸，也不是纯粹的血肉墙。第一阶段用地面导电液划分区域，第二阶段向供能接点扩张。

四个外部供能节结可逐个击破；每毁一处，邻近电网停电，同时释放一次明确预警的最后脉冲。破坏上方冷却器使核心暴露更久但暂时淹没近路；关闭两侧阀门则保留干燥路线，战斗较长。演出按玩家操作显示被淹的样本架或仍完整的医生物品，决定 E06 的证据形态，但两者均可得出核心结论。

## B04 蕾娜·维斯｜C06｜PMC 王牌

她用移动盾、短步冲刺与破障筒压缩距离，换弹时要求队员掩护，体现职业配合。战斗开始前给玩家手动封门的机会，可减少一名增援。

破坏盾臂后她改用双手步枪、攻击更快但可被正面压制；破坏腿侧散热片后冲刺改为定点烟幕换位；打掉护目扫描器后失去穿烟追踪。生命归零是失去继续作战能力，进入缴械演出，不默认处决。扫描器被拆时她说“陆栖”，未拆时先喊编号、看清脸后才改口。黑箱是否保留另记 `pmc_blackbox`，不与打身体的伤害类型混用。

## B05 沈砚霜｜C07｜曾经的伙伴

她的目标是打掉陆栖回收应答器。玩家战前只知道她开火了。战斗射线优先指向装备边缘，她会主动射断能拖慢追猎无人机的电缆；这一行为既能帮助玩家，也像是在封路。

破坏狙击枪定位器后，她改用近距离抓取接口；破坏腿部外接供能后，她停止追逐，靠射击电缆与关门限制路线；破坏通信模块后停药命令短暂中止，给予她一个说出半句话的窗口。战后播放不超过八秒的已发生射线轨迹，明确她不是来杀人的。若玩家先打掉通信模块，她亲口解释；否则苏弥恢复枪械记录。两条路径都要求沈向陆栖道歉，不把暴力保护写成无需同意的浪漫。

## B06 闻雪 / 病房供能架｜C08｜主角的“失败版本”

闻雪被固定式供能架困住，反射模块把攻击转向周围；她一度主动维持这个局面，想证明自己不是可以被丢弃的数据。战斗对象是外部回路，不把瘫痪的人当可随意射杀的靶。

打掉追踪镜头后炮塔只攻击固定区域；断开抑制环后感染群失去同步，但闻雪的过载风险上升；替换冷却盒后核心伤害窗口缩短，却允许医疗队安全靠近。界面明确“切断控制、保持供能”的双目标，并提供固定数量维修电池。若冷却盒耗尽，备用开关可人工维持，但玩家必须在防守中等待。成功演出由闻雪自己断开最后一条线；被救后仍由她决定病历公开范围。

## B07 顾青禾 / 定海｜C11｜完全适配者

第一阶段同时指挥自身机体与两台无人系统，第二阶段在指挥网络被破坏后用单机高压制火力。她会点出玩家曾牺牲过什么，但只引用确实发生的选择，不伪造道德指控。

破坏肩部指挥器让无人系统进入原地防御，为玩家开放通道；破坏背部冷却器让压制射击变成短爆发，近身危险上升；拆掉膝部稳定器使她失去大范围跃迁，但每次落地生成可利用的地形破口。驾驶舱在主战斗中有明确保护罩，最终阶段才显示是否允许继续攻击。保留驾驶舱，她亲手停火；打穿则由现场医护断开控制并抢救，不能用一场血腥处决替代制度问题。

## B08 回收室 / 归档员｜C12｜最终实验系统

由门禁、样本车、维护机械和外部镜像组成，没有一个万能心脏。它的威胁是通过服务顺序决定谁先失去治疗与通行，不是突然获得超自然力量。

三个“部位”是医疗代理端、武装执行端、审计回流端。医疗端切控制而保留供电；武装端撤销密钥后无人机可被断电回收；审计端撤去身份数据并发布签字链。每完成一处，真实地改变攻击种类、地图门禁与无线电语气，并失去一种主角增强能力。只摧毁外壳会在另一终端重建，第一次即可由 UI 告知原因，不能让玩家反复盲打。系统最后转而报价，选择拒绝与否由玩家决定。胜利标志是人、设备与记录分别移交到可拒绝、可复核、可独立维持的体系，之后才播放离场演出。

## 章节制作与复用边界

主线地图共六套模块：港口/旧城、医院/实验楼、商场、军用后勤、地铁/隔离病房、终局控制设施。复用墙体、门和家具，不复用同一段“走廊尽头拿文件”当剧情。主要角色八名配角加一名主角使用独立轮廓与面部；感染者至少三种作者模型变体，非人型敌人至少三种机体。八名 Boss 中 B02/B08 主要复用机械资产，B04/B05/B07 复用主要角色并追加装备；B01/B03/B06 需要专门建模与动画工期。

每章发布前必须验证：核心线索可由主线取得；可选对话不阻塞通关；所有路线能在腿部模块损坏时到达；选错武器不软锁 Boss；死亡/跳过/读档不重复发奖励或改变已提交的关系选择；每一层真相都能在日志中指出至少一个被重新解释的旧事件。
