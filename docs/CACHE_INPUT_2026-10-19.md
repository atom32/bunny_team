# 补给箱键盘与手柄操作

本批改善实际搜刮操作：开箱后可直接用键盘或手柄拿取、换物和关闭，不再需要先用鼠标找回焦点。物品所有权、整堆拾取、负重、奖励、存档和战斗计时不变。当前为本地 WIP，未提交、未推送、未发布。

## 操作变化

- 开箱默认选中第一行“取走”；取走一行后选中下一行，最后一行取走后回到关闭按钮。
- 上下方向键或手柄十字键按行移动，左右切换拿取与交换，Tab 在当前箱内循环。焦点进入长列表下方时自动滚动；重建列表、改变分辨率和语言切换保留位置。
- 交换下拉框确认后返回下拉框，不把焦点留在已释放的旧控件。不能交换的按钮不进入 Tab 路径。
- 焦点采用深色双像素边框，避免橙色“取走”按钮上的橙色细框难以辨认。底部提供导航、确认与关闭提示。
- 每一行提前显示该整堆物资的负重差额（两位小数），随实际携行重量变化更新；拿取按钮仍可尝试，以便读到完整拒绝原因。无拆堆、免费丢弃或自动兑换。
- 当前运行时的内置菜单动作缺少手柄事件，补入设备无关的 A 确认、B 返回、十字键四向移动；保留原有键盘菜单事件、玩法手柄事件和用户改键。重复初始化不重复添加。
- **A 同时是翻滚键**。交互窗口占用确认输入时不再启动翻滚；走动、受伤、换弹与战斗计时仍继续。窗口关闭后正常翻滚恢复。
