# Alpha 0.1 — 有限武器改装

2026-10-03。**本批增量 PASS；完整 Alpha 仍 IN PROGRESS。**

## 玩家流程与规则

完成第三份跨局委托恢复工作台后，基地 Workshop → 军需处 → 武器改装。按具体武器实例选择；相同型号可有不同配置，显示短 ID 以区分。

| 配置 | 装填耗时 | 敌人枪声听距 | 额外重量 | 费用 |
|---|---:|---:|---:|---|
| 标准 | ×1 | ×1 | 0 | 拆除免费，无返还 |
| 快装套件 | ×0.8 | ×1 | 0.8 kg | 120 信用点、零件 2、线路 1 |
| 消音改装 | ×1.15 | ×0.5 | 0.35 kg | 180 信用点、零件 2、织物 2 |

一把枪一个功能位，不能叠加。适用现有单弹丸 hitscan 枪械，霰弹枪/火箭筒排除。伤害、射速、弹药、枪口、弹道、基础 WeaponDefinition 资源均不改变。未改装行为保持原值。

当前多数步枪/SMG 的基础散布为零，因此没有添加毫无效果的“精度 ×0.75”标签。快装和消音均作用于实际 Player 装填计时/动画时长与 CombatNoise 的敌人听觉半径。墙体衰减仍应用；消音不意味着敌人看不见玩家、听不见脚步或碰撞。

## 所有权、持久化、重量

`ItemInstance.fitting` 是实例数据，不是永久 profile buff。保留实例 ID；携行、checkpoint、成功撤离和正常 JSON 保存保持配置，失败失去武器及其改装。旧档缺失字段表示标准配置；非法类型、未知 ID、非兼容物品上的配置拒绝加载/入库。沿用 schema 4 的可选实例字段，不更改既有身份/任务语义。

安装先验证副本、扣精确材料/费用、验证重量并保存，成功后才发布。保存失败不扣除；重复安装同配置拒绝；出击/挂起/恢复异常时不能在基地改装。替换无旧改装退款，出售仍按原装备残值，不靠拆装套利。

仓库校验、携行计划、实际部署、结果回收和重量 UI 使用同一个实例重量计算，已装弹匣重量照旧计算。
