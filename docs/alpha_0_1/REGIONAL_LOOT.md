## 先复用已有地图

代码已有四处可进入建筑、市街与庭院、六个出生候选、四个出口（每局分配其中两个）、M 路线图和变化的档案/调查地点。本批没有重造地图/导航/出生或复制一套撤离系统；只给原来使用同一补给表的八个室内普通点分配地域资源池。

| 地点 | 每次普通点成功产出的权重 |
|---|---|
| 市政办公室 | 电子元件 45%，线路 30%，数据盘 15%，废料 10% |
| 药房 | 敷料 45%，医疗包 25%，织物 25%，零件 5% |
| 公寓 | 织物 60%，线路 15%，废料 15%，敷料 10% |
| 维修店 | 零件 40%，线路 30%，发射药 15%，废料 15% |

这些是条目选择概率，不是保证每次来都有货：原有普通点 65% 启用率保持不变，每栋两处普通点；单点产出数量按原物品/新表的 1–3 件范围，药品仍为独立一剂。四处原高价值点与六处街道综合补给点未改，不额外增加箱子或刷出数量。

直接连接现有需求：药房提供局内医疗；公寓织物用于诊所/背包/敷料；办公室与维修店材料用于工作台、改装和弹药制作。不是新建仅能出售的一套材料 ID。

M 地图加入静态资源情报，明确“不保证每局产出”；不揭露当前启用点、物品抽签结果或隐藏敌人。中英文同源提示。玩家能把跨局委托/配方缺口变成要去的地点，而不必只沿随机箱子碰运气。
