## 实现

- 靠近城区档案终端按交互键，开始 **8秒本地读取**。可在原交互半径内移动、瞄准、防守；离开、死亡、出击结束或受伤会中断，不能隔空完成。
- 读取中再次按交互键，自愿切换 **最多3秒快速上传**，立即在终端位置产生45米当地警报。不是玩家实时坐标广播；继续复用已验证的听觉/调查规则，不改AI、伤害、敌人数。
- 本地读取完成后保留原来的25秒警报缓冲。快速上传已发出的警报不会在完成后再发一次，也不会因为受伤或离开撤销。
- 两种方式完成后推进同一个目标、解锁同一个条件出口，不加奖励、不改战利品或经济。无条件撤退口始终保留。
- 读取/上传进度以模拟时间推进，暂停冻结。血量信号保证不足1点的伤害也中断，不依赖取整后的统计计数。
- 首任务8秒调查和中继站12秒修复保持原状；仅城区档案使用新实现。

这不是两套新的任务系统，只在现有 ObjectiveInteractable、RecordsAlarm、InteractionComponent、SortieCheckpoint 之上增加一个城区终端实现。
