# Alpha 0.1 — 键鼠操作设置

入口：主菜单 Settings → Controls，或局内 Esc → Controls。设置界面暂停模拟；退出设置回到来源界面。

## 实际功能

- 可改移动四方向、射击、闪避、轻步、装填、切枪、交互、敷料、医疗包、路线地图的一个主键鼠绑定。
- 点击操作后按键或鼠标按钮；Esc 取消本次捕获。重复键和保留键不接受，需先把占用它的操作移到另一个键。支持鼠标左右中键和两个侧键，不把滚轮当作持续按键。
- Esc/F11 保留给暂停和全屏；不提供 Ctrl/Alt/Meta 组合快捷键。Ctrl 本身可以单独绑定。手柄既有轴/按钮保持，不声称提供手柄重映射。
- 编辑和恢复默认先改变草稿；Apply 成功写入设备本地 `user://controls.cfg` 后才应用。保存失败保留旧绑定。返回丢弃未应用草稿；配置不属于 Person/仓库/出击存档。
- 首次启动从项目真实 InputMap 捕获默认值，并补装医疗/地图动作。坏配置整体退回默认，避免部分应用导致重复键或无法操作。
- 应用或退出暂停释放动作，避免切换绑定后继续移动/开火。只替换键鼠事件，不删除手柄事件。
- 实际交互、拾取、补给箱、撤离、医疗、切枪、地图和首任务教学显示当前键位，不再写死 E/Q/H/J/M/WASD。

## 验证范围

- control_settings_test 36 检查：保存、冲突、保留键、坏配置、保存失败、手柄保留、释放按键、实际暂停 UI 的捕获/取消/应用/重置、医疗 HUD；生产 Streets 中通过真实 InputEvent 按新 F 交互终端、N 打开地图，旧 M 不再开关。
- 独立进程从配置加载：3 检查，新 F 实际对应 interact，旧 E 不再对应。
- Forward+ 1280×720 中英文设置面板已渲染检查；滚动列表显示全部 13 个操作，底部恢复/应用/返回可见。不是人工完整试玩。
- 全量运行、冷导入、旧测试、路线/存档探针详见 controls_validation.json。
- 原 streets_layout_test 直接调用 `_unhandled_key_input` 的测试驱动随输入接口迁移为真实 InputEvent（等待节点进入树、独立按下/松开事件）；原有 M 打开/关闭、布局、导航和任务断言全部保留。首次全量运行在旧回调处失败的日志保留，修复驱动后重新运行，不伪造旧结果。

## 保持不变及后续

没有修改移动速度、伤害、医疗耗时、敌人逻辑、地图布局、经济、存档语义或角色资源；project.godot 无需新增 autoload/重写用户配置，复用既有 FlowMenu 启动生命周期。

这是必要设置的一部分，不代表完整 Alpha 完成。仍需目标硬件性能检查、可读性/操作真人验证、更多地点目标及多局经济/节奏验证。高级组合键、双绑定、完整手柄设置不属于本批。
