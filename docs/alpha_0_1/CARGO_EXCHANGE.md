# Alpha 0.1 — Cargo exchange

2026-10-03 — 本批补足局内战利品取舍，不是新增库存框架。

## 行为

- 供给箱面板可选择一组已携行战利品，再与一组箱内物品交换。
- 整组交换，保留双方实例 ID、数量、耐久和改装数据；换出的物品留在原箱位，后续可取回。
- 出让项仅限未装备、带 loot 标签的战利品。不能出让武器、护甲、背包、弹药或医疗物资；不改武器/治疗运行状态。
- 先验证独立库存候选（含已装填弹药占用重量），容量或选择无效时双方均不变化。交换后仍受真实容量限制。
- UI 继续使用原距离限制与 Loot 输入捕获，世界不停，敌人仍可攻击；远程/过期按钮不能交换。
- 复用现有 LootSpawnPoint / LootPickup 和 checkpoint，未增加存档格式或地面掉落系统。
