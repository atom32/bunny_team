## 直接观察到的问题 / Alpha 优先级

1. **P1：整备信息容易误读。** 第一次库存药品为 0，输入仍显示敷料 2 / 医疗包 1；第二次步枪弹库存 83，输入显示 90。实际携行摘要正确地显示药品 0、弹药 83，但玩家需要再读小字才能确认不足。宜明确“请求 / 实装 / 缺口”，避免误认为已带药。
2. **P1：交互面板与战斗瞄准耦合。** 拾取按钮改变鼠标位置时，角色朝向与背景取景同步改变；`PlayerController._update_aim()` 每物理帧读鼠标，战斗镜头跟随 aim_direction 前移。建议明确面板打开时的瞄准/镜头输入归属，不改变敌人继续行动的设计。
3. **P1：战场层级与世界文字可读性。** 1280×720 下人物在多张战场图中仅约 50 像素高，终端/箱子/撤离的世界文字很小，场景常由路面与屋顶占据。镜头源码本身约为 53° 斜俯视，**不是证明镜头错误地变成 90°**；应评估取景尺度、关键物对比与标识，而非修改人物比例。
4. **P1：路线提示不是路径提示。** 首任务终端标记显示 W/NW 距离，但入口位于建筑南侧；实际需要找门绕行。门附近 E 提示有效，进入后屋顶隐藏有效。宜先指引入口，再指引室内终端。
5. **P2：首次 Loot 尚未产生负重取舍。** 一枚核心使重量从 13.3 变为 19.3/100 kg，拾取与入库反馈清楚；这一局不能证明背包决策已经成立。需要在后续正常局观察“带药/弹/战利品”的实际冲突，不据此直接改数值。

有效部分：掩体阻挡有明确叉标与文字、听觉方位提示能用于转向、箱子显示物品/价值/重量且有成功反馈、返航奖励与一次升级形成可见的小闭环、城区地图给出资源与两种撤离条件。
