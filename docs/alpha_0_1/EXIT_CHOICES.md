# Alpha 0.1 — 撤离与地点目标取舍

2026-10-03。完整 Alpha IN PROGRESS。

## 当前规则

复用旧城区原四个出口/每局两个分配出口。按出生点距离排序的最远分配出口始终允许直接撤退；另一分配出口要求完成本局 `streets_terminal` 档案交互。对面庭院调查不是开门条件，完整任务不是撤离前提：玩家仍可拿少量战利品直接撤回，或者绕到档案地点换取另一条可用路线。

- M 地图分别列出两个出口及实时条件，绿色开放、琥珀色锁定。
- 锁定出口仍提供近距离提示，交互返回明确条件，不消费物品、不结束 session。
- 档案实际交互完成后，第二出口立即开放。任务状态已随 sortie 保存，恢复后不会重新要求交互。
- 永远保留一个无任务条件的分配出口；未分配的两个出口继续关闭。不是四个出口都能使用，也不是强迫所有局完成任务。
- 距离排序是原有直线距离，不宣称穿过掩体/庭院的实际步行路线一定更短。

没有新地图/碰撞/导航，没有修改出生、AI、武器、伤害或玩家模型。通用 ExtractionPoint 新增默认空的可选 required_objective_id；原 First Mission/其他地图不设置该条件，保持原行为。成功仍通过已有 SortieSession.complete_extraction、Result 和原子结算，不创建平行奖励逻辑。

## 验证范围

新增 exit_choice_test：35 项检查，六个出生候选各验证一个开放、一个条件、两个未分配出口及距离关系；实际锁定交互不结算；档案 terminal 真实交互后开放；session 保存/恢复保持锁定/开放；任务未完成也能经无条件出口撤退；条件出口成功后重复撤离拒绝、正常 Result commit 返还物资。

Forward+ 1280×720，中英文地图锁定/开放状态实际渲染检查；是受控生产地图组件测试，不是完整真人路线。测试中的另一分支 clone 用独立出口节点验证，避免 clone 的 extracted 信号误触发当前 Battle 的视觉收尾；不修改生产逻辑来照顾夹具。

完整回归与最终结果见 exit_choices_validation.json。
