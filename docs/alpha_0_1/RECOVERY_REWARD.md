## 规则（实际经济 Gameplay 变更）

- 完成任务并撤离：首任务600，其他任务450，保持原总奖励。
- 未完成任务但带回新增物资：100回收奖励，保留提前撤退的价值。
- 仅带回原有装备/弹药、没有新增物资且任务未完成：0信用点奖励，仍成功撤离、保留返回装备，不算死亡/失败。
- 死亡/放弃仍无奖励，原携行损失不变。
- 不追溯扣除旧存档已发资金，不改存档schema；只改变后续尚未结算结果的奖励计算。

## 不能用新ID判断Loot

弹匣中的原有子弹在结束时可能重新物化为新实例ID。如果直接看“ID不在出击列表”，空跑仍会被误判为新Loot。
现用仓库保存的精确出击实例数量，按物品definition汇总，与实际返回数量比较正增量。自己弹匣重新生成ID或消耗弹药后返回都不能制造回收奖励；新搜获弹药必须真正增加带回数量。
Result的NEW SUPPLIES也用同一个净新增计算，避免把原有弹匣子弹显示成战利品。空返显示0 / NO NEW SUPPLIES，配套中文翻译。

## 范围和限制

这不是“Gameplay不变”：实际变更了撤离经济和Result净新增统计。战斗/AI/撤离条件/死亡规则/存档格式/角色/地图/WIP未动。
这只消除完全空跑收益，不证明所有经济平衡成立。单件低价物资仍满足100补贴，后续需要真人路线/风险反馈，不在此批任意加门槛。
