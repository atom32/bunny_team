## 玩家规则

- M 地图与常驻提示提前说明：读取本局档案后，25 秒模拟时间触发一次警报。
- 实际档案交互成功后开始倒计时；再次调用不会重置。档案仍按既有规则立即开放条件出口。
- 警报在档案终端当前位置发出局部声音，半径 45 m；沿用现有墙体听觉衰减（遮挡时 ×0.45）。能听到的现有守卫调查终端，而不是获得玩家实时坐标。已确认目视交战的敌人不被声音强行转向。
- 不刷新增援、不关闭撤离口、不改敌人数值。玩家可以选择马上离开、绕行或继续搜刮；倒计时内也可正常撤离。
- 暂停冻结倒计时；保存并跨进程恢复保留剩余模拟时间。出击结束后不再发出延迟噪声。只触发一次，不持续追踪玩家。

## 实现边界

`StreetTerminal/RecordsAlarm` 是终端的无碰撞子节点，随每局档案地点移动。`objective_interacted` 信号在真实任务完成后启动它。没有新增 AI 框架，直接使用 CombatNoise / EnemyAwareness。

世界 checkpoint 增加可选 records_alarm 字段，完整校验 phase 与 remaining 后再应用世界状态。旧 checkpoint 缺失字段：若档案已完成，视作事件已消费，避免加载旧档突然补发警报；否则保持未启动。原节点列表与布局签名不变。

中英文提示已接入常驻路线 HUD。当前声音复用 UI/radio 提示音，**尚不是正式警笛音效**；未制作新模型、人物或纹理。
