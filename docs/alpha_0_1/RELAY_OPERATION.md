# Alpha 0.1 — 可选择的中继维修行动

> 历史批次报告：相关实现已纳入 `c1cebae`。文中的未提交状态、测试数字、临时路径及后续计划记录当时情况；当前进度与剩余事项以[最新交接](../../Handoff.md)为准。失败与修复记录保留，不代表当前仍失败。

## 玩家流程

首次教学任务之后，基地 Operations 可选择：

- **档案行动**：原有取档案、对侧庭院调查。
- **恢复中继线路**：到市政办公室和维修店，各启动一次 12 秒现场维修，然后撤离。两处可任选顺序。

维修不需要额外材料。玩家需留在既有交互半径内，仍可观察和防卫；离开、受伤、死亡或出击结束会中断当前尝试，重试从 12 秒开始，已完成的另一站不丢失。启动产生 18 m 局部噪声，沿用墙衰减与敌人真实听觉，不刷新增援或提供玩家实时坐标。

读取档案在新任务中是可选项，仍会触发档案警报并开放条件出口。两站维修完成不凭空授予档案，始终保留原无条件撤退口；无需完成任务也可携带已取得物品撤走。

主菜单本次运行中保留选择，重启默认档案行动；**正在进行的任务以持久化 session.mission_id 为准**，恢复不会改成默认任务。首任务未完成者仍只进入教学，不允许选择绕过教学。

## 成长与持久化

- 新行动使用现有 MissionDefinition / ObjectiveState / SortieOutcome，不建立平行任务、物品或奖励系统。
- 正常完成及成功撤离使用现有任务奖励；失败/未完成不伪造完成。第五个基地委托接受档案或维修行动；已累积进度和之前委托保持。
- 世界 checkpoint 保存每站剩余时间与损伤基线，恢复实际 actor/session 绑定；完整验证通过后才改变现场。伤害监听使用真实健康变化，避免整数任务计数漏掉小数伤害。暂停冻结维修。
- 新增两站仅存在于维修任务；原档案任务的节点集合、碰撞、导航不变。维修站复用现有终端外观，无新人物/GLB/AI 资产，无新增碰撞。

## 本批不代表完成的内容

新增的是**实际任务玩法**，不是“Gameplay 完全未改”的视觉声明。伤害/枪械/AI 数值、经济公式、原有档案/教学目标、人物和官方资产没有修改。只是第一个不同目的的旧城区行动，不是大型任务系统；现场音效仍复用提示音，维修站外观也沿用终端。

完整 Alpha 继续进行：目标硬件性能、可读性/声音与任务节奏、10–15 次人工出击的风险收益及重玩验证仍未完成。
