# 淡出屋顶截获瞄准 — 实机问题修复

2026-10-03。第八局实际点射029/030/032/033的只读日志均记录瞄准高度约3.69m，正是维修店屋顶上表面。不是把所有未命中归咎于玩家或武器散布。

## 根因与修正

镜头遮挡只改变网格透明度，屋顶碰撞仍存在；玩家鼠标拾取射线首先撞上淡出的屋顶，导致瞄准点向上偏移。实际子弹又撞上屋顶下表面，HUD提示遮挡。屏幕上屋顶几乎不可见，因此反馈很难理解。

- 街区四间可进入房间的屋顶显式标记 `aim_cutaway_roof`。
- 原镜头遮挡器只对当前遮住玩家的标记屋顶发布临时 `active_aim_cutaway`；离开/场景退出清理。
- 鼠标选点跳过当前切开屋顶，继续原有可见敌人/墙面/地面拾取；不是忽略所有淡出物体。
- **墙壁仍可截获鼠标；屋顶和墙壁的碰撞层、形状、弹道、寻路完全不改。** 上射子弹仍能撞屋顶。原有未观察敌人过滤仍保留。
- 没有改角色、美术资产、伤害、射速、敌人AI、治疗、存档。玩家输入选点行为有针对性修正，不宣称“任何 gameplay 代码都没动”。
