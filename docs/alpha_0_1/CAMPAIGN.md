- 同时只有一个当前委托。必须在基地领取后才开始下一步，不能把之前的击杀/出击次数自动算给后续委托。
- 只有成功撤离且**正常返回结算**的战果会累积。侦察委托要求完成局内任务；清理委托只要求存活带回击杀，不强制当局侦察完成。失败/放弃不增加进度，也不抹掉以前已结算的进度或设施。
- 上交精确消耗仓库现存材料，剩余数量、装备及 ItemInstance ID 保留。可用以前存下的材料；不是“本次发现”限定，也没有新增 FiR 字段。

- 弹药工位配方：3 金属废料 + 2 密封发射药 → 30 发已有 5.56 AP。没有新增武器或改变原 AP 参数。
- 信任供货只优惠装备，向上取整；弹药/医疗价格和出售价格不变。不能低价购入再原价出售刷钱。
- 所有配方仍消耗物资；死亡损失、应急资格、携行、普通贸易、仓库与结算规则保持原有行为。

## UI 与持久化

- 基地总览：中英文委托列表、条件、当前进度、材料数量、奖励、设施状态和“上交 / 领取并保存”。后续委托可查看但不能提前领取。
- 普通工坊交换页显示已解锁配方，买入按钮显示实际优惠后价格。API 也检查解锁，不是只禁用按钮。
- Result 左侧显示**返回结算后预计**的委托进度，不在预览时发奖励。Loot 中当前委托材料用金色标记，提示撤离后上交。
- schema **4** 保存 `campaign = {version:1, stage, progress}`；设施由已领取阶段推导，不引入第二套设施解锁数据。schema 1/2/3 迁移保留旧库存/ID/首任务/AR 升级，委托从第一步开始，不虚构历史完成。
- 新 schema 丢失 campaign、非法版本/阶段/数量、越界进度或未知字段拒绝加载，不静默清空进度。
- 战果记录位于原 `SortieOutcomeService` 幂等提交内，重复 outcome ID 不增加委托进度。领取先生成候选状态、原子存盘，成功才发布；保存失败不扣材料、不发钱、不开放设施。
- 领取带委托 ID 校验，旧按钮/连续点击不能误领下一份；活动出击、挂起出击和存档恢复期间禁止基地领取。
