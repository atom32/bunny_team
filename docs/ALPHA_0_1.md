# Alpha 0.1 开发与验收

2026-10-03，用户授权按单机斜俯视角搜打撤 Alpha 推进。目标是可持续游玩的任务、风险和成长循环，不是再做一段演示路线。本文件覆盖完整目标；局部交付不代表 Alpha 完成。

## 开发顺序

1. **战备经济**：有限初始装备；死亡/放弃损失携行物资而非基地库存；交易补给、多用途材料、制作/交换；失败后可恢复；旧档保留与交易原子保存。
2. **战术生存**：敌人视觉/听觉、最后已知位置与搜索/脱战；不同战术职责；医疗与耗时治疗；视野隐藏和镜头遮挡分离；瞄准/掩体反馈一致。
3. **长期成长**：跨局任务链、奖励与解锁、基地实际功能、有限装备改装、背包携行决策；旧任务/一次升级接入而非并行重复系统。
4. **区域与产品闭环**：资源分区、重要地点、撤离选择、可预判事件、阶段终点；单机挂起续玩、输入设置与可读性；完整路线、跨进程存档、兼容/性能与真人试玩。
5. **入口与基地体验**：主菜单的主角构图与游戏身份、可信的紧凑 Hideout、功能区域与实际空间对应、菜单/基地/出击/返回的连续过渡。属于 Alpha 正式范围，不是额外包装；2026-10-04 确认范围，2026-10-05 已集成紧凑 Hideout 与站立/坐姿动画。

## 当前实现决策

- 常规死亡/主动放弃将损失本次带出的装备、弹药和物资。基地中未携行的物资、信用点和永久解锁保留。
- 新档是 AR + SMG、轻甲、背包、有限弹药与初始信用点，不再发放整个测试武器库。现有用户存档中的装备不删除，也不再在加载时补发失去的武器。
- 没有可用枪弹组合且财力不足时，提供受条件限制的应急整备，避免软锁；不能通过反复点按钮刷库存。
- 交易/制作先验证候选状态并持久化，成功后才发布到运行状态；失败不能扣款或吞物品。
- 初始商人/材料/价格是 Alpha 平衡起点，不声称经济已通过多局真人验证。
- 测试中“死亡不损失装备”的旧规则必须迁移为携行损失、基地保留、重复结算安全；不通过关掉新规则或隐藏兼容分支保留旧结局。
- 角色模型、贴图、官方资产和已有用户 WIP 不动。只扩展既有系统，不引入大型框架。相关实现已纳入 `c1cebae`，后续修改按实际范围处理。

## 完整完成标准

- [ ] 多次出击形成投入、风险、收益和恢复循环；死亡有代价但不使存档失去继续能力。
- [ ] Loot 有立即使用、出售、任务、制作、解锁等不同用途，并能改变撤离选择。
- [ ] 可以侦察、绕行、伏击、脱战；敌人不会无条件知道玩家位置。
- [ ] 斜俯视角的发现、遮挡、掩体和弹道规则清楚且一致。
- [ ] 医疗、负重、补给和背包取舍实际参与局内决策。
- [ ] 跨局任务、基地设施和装备改装形成阶段性成长及明确终点。
- [ ] 区域有资源语义、不同路线和撤离条件，不是仅增加面积与道具。
- [ ] 单机挂起续玩、必要设置、旧存档迁移/异常恢复及跨进程一致性。
- [ ] 主菜单清楚呈现主角体态与游戏身份；Hideout 有连贯空间和明确功能区域；菜单→基地→出击→返回具有连续体验，不只是角色预览器与功能面板。
- [ ] 新旧回归、正常 UI 图形完整路线、冷导入、目标硬件性能验证。
- [ ] 以约 10–15 次出击、2–4 小时为首轮内容/真人测试目标；有实际节奏与重复游玩证据，不能用自动化通过替代。

状态（2026-10-05）：**IN PROGRESS**。战备经济、单机续玩、医疗、感知/视野/掩体、战术职责、委托/设施、有限改装、精确携行、容量/战利品交换、区域资源/条件撤离/档案操作、维修任务、键鼠设置、HUD/脚步声音，以及紧凑 Hideout 和待机/坐姿动画均已集成至 `c1cebae`。

最新已有 Windows 验证为 59 个测试场景、79/79 验证项通过；本次 macOS 同步未重跑。最低硬件性能、真人连续 10–15 局 / 2–4 小时的经济与节奏、听感仍待验收；坐姿过渡与环境音属于后续表现改进。当前证据与剩余事项见 [交接](../Handoff.md) 和 [验收审计](alpha_0_1/ALPHA_ACCEPTANCE.md)。

## 2026-10-03 — 单机出击挂起 / 续玩

上面的“中断后退回出击前保存”缺口已补上。**这是 Alpha 的一个完成项，不是整个 Alpha 完成。**

### 玩家能使用的流程

- 正常部署前先持久化本局；局内每 2 秒模拟时间自动保存，在拾取/击杀/任务推进后也请求保存。
- Esc → **保存本局 / 返回主菜单**或**保存本局 / 退出游戏**，再启动 → **继续出击**。窗口关闭也保存当前出击，不暗中判死。
- 恢复同一 sortie ID、携行物品 ID、生命、位置、弹匣与装填/闪避计时；已拿走的 Loot 不重刷，已死敌人不复活。门、可破坏物、警报/增援、任务/终端/撤离进度和在途火箭随世界一起恢复。
- 敌人待发射击保留剩余延迟和锁定目标；同时保留当前开火表现姿态，避免恢复后人形 NPC 或 KITE 的枪口跳位。只是序列化已有运行时姿态，没有修改模型、骨骼 rest pose 或动画源。
- 保存中的出击不能再部署另一局或交易基地库存。主动放弃仍执行携行损失；成功/失败结算与移除 checkpoint 在同一次原子写入中完成，保留 outcome ID 的幂等保护。
- 保存失败保留内存和上次有效文件并提示；不兼容的世界/布局拒绝加载并保留文件，不静默替换成新的一局。
- 存档升到 schema 3，同一 envelope 内保存基地状态与 checkpoint；兼容 schema 1/2，并保留已有库存、装备 ID 与经济数据。

### 明确边界与后续

- 强制结束进程会回到最近的有效自动保存，可能回退约 2 秒模拟进度；不是逐帧重放或零进度损失承诺。显式挂起先保存当前状态。
- 瞬时粒子、无碰撞尸体、Loot 弹窗、镜头震动不保存；实际死亡、掉落及任务状态保存。恢复后的随机行为不是逐帧确定性重播。

## 2026-10-03 — 敌人感知 / 搜索 / 脱战

- `EnemyAwareness` 保存巡逻原点、最后观察、警觉度、搜索时间和当前意图；只有真实目视和局部声音能更新目标位置。导航与表现不再持续读取墙后的玩家位置。
- 人形与 KITE 的视距/视角/识别延迟/搜索时间不同。保留原伤害、射速、射程、移动速度、弹道与攻击延迟；本批明确改变 AI 感知与巡逻/交战决策，不冒称 Gameplay 完全不变。
