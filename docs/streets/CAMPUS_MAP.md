四栋主要可进入建筑有独立室内布局：阅览楼以书架、阅览桌和中央通道组织；医务室分柜台、药柜、候诊与诊疗区；宿舍分收发/值班区、走廊和双层床位；维修房分工作台、工具柜和车辆维修车位。复用基地已有的Poly Haven家具模型与材质，来源及校验记录见 `assets/environment/compact_hideout/{SOURCE.json,ASSET_HASHES.json,polyhaven_downloads.json,inherited_polyhaven_downloads.json}`。家具实测包围盒参与既有碰撞与导航；不新增搜刮交互、库存或物品规则。进入建筑时屋顶完全淡出，退出后恢复，碰撞和固定相机角度保留。

总物资点仍18个：12个室内、6个室外。高价值缓存从四个缩为档案楼一个，其他点提供普通区域物资。初始敌人为3名，保留现有角色、战斗数值与增援机制。入口两侧的前场接入校道；湖面不可通行，环湖步道可走。

建议自然形成的路线：

- 基础补给：宿舍 → 医务室 → 分配出口；生活与医疗物资有明确目的地。
- 维修补给：后勤门/服务路 → 工坊及托盘 → 校道 → 分配出口。
- 较高风险：教学区 → 阅览楼资料/缓存 → 双湖步道或主轴 → 分配出口；沿用档案警报与撤离条件。

这些是关卡路径，不生成新委托、导航提示或剧情推进。六个出生候选、四个出口、每局分配两个较远出口的机制保留；出口稳定ID不变。地图显示实际道路、湖与建筑，以及原有公开任务/出口信息，不泄漏随机物资或敌人。
