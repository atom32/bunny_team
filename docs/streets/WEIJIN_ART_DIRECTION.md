# 整校园美术细化 / 2026-10-23

目标：继续细化整校园地图，使之与当前游戏的美术风格一致。不是用新调色掩盖几何粗糙，也不以某个精修角落代替全图。

## 现有风格依据

当前角色为细腻二次元人物；旧校园战斗画面使用有尺度的砖墙、石路、灰瓦、窗框、阔叶树与克制磨损。
保留明亮校园，不把“战术”理解为全图废墟或黑灰滤镜。纸白/深灰/信号黄属于操作UI与功能牌，
不是把所有自然物体涂成UI色。参照实际 `docs/ui_remake_2026-10-23/complete/combat.png`、
`scripts/world/streets/courtyard_tree.gd` 和现有校园材质，不新增全屏卡通描边框架。

## 完成门槛

1. **真实地理不退化**：校界、4湖、467个保留建筑轮廓和路网、DEM原数据、1:1比例不变；原有碰撞与旧档保持。
2. **整片建筑有细节层级**：宿舍/住宅、教学/图书馆、服务设施用一致而有区别的砖、浅抹灰、石基与灰瓦；
   门窗有实体窗框/窗台，楼体有基座、檐口、屋面收边；有来源的坡屋顶不再一律画成平盖。
   已知地标能辨认，近景不依赖低分辨率重复窗贴图；远景LOD不产生无窗白墙。
3. **地面与湖岸**：草地不再是浅黄平板；有路面、路沿、排水与接缝层级。水面去除菱形重复网格，
   四湖统一自然蓝绿浅深关系，湖岸有石质压顶、局部湿痕及生活尺度。
4. **植被**：近景使用现有风格的分枝/叶片，而非三个球；全图有尺寸/朝向差异，远景有性能合理的LOD。
   植被、道具不塞进建筑、湖面、运动场与通行道路。
5. **校园生活与战术可读性**：沿道路/湖岸合理分布灯杆、长椅、分类桶、自行车/车架、导向牌与少量维护设施；
   不乱撒战斗残骸，不造新的剧情任务，不用视觉道具假称可互动掩体。
6. **实际可看、可走**：勘察UI可收起以看场景；航拍、角色战斗尺度、主楼、湖岸、宿舍、入口都要原生渲染检查。
   合成输入走动与湖岸碰撞、菜单/基地入口返回、只读存档、旧地图回归需仍通过。
7. **证据与边界诚实**：保存同机位前后图、远近景和回归结果；保留“高程为区域DEM、多数楼高/立面/种植为估算，
   主线未迁移、楼内未重建”的说明。材质与程序几何改进不能冒称实地测绘或最终照片级复刻。

上述门槛同时满足才完成本轮整校园美术细化；测试数量本身不能替代视觉检查。
