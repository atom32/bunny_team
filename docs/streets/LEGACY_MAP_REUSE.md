## 后续翻新方向：封闭的赛博设施

旧办公室与室内战斗通道适合复用为小型封闭研究设施，参考用户提出的实验室气质，但制作原创空间。先翻新再接入地图选择；当前尚未接入新的实验室地图。

- 将办公室、入口门、掩体和警报空间整理为安检入口 → 更衣 / 缓冲区 → 设备与样本区 → 运维通道的连贯布局，先审核尺度和动线再处理材质。
- 强化冷白工作灯、局部青色设备状态灯、封闭机柜、线缆桥架、玻璃隔断和实体设施编号；保留使用痕迹，不用满屏霓虹替代空间设计。
- 通过封闭门、停机设备、遗留工作记录和局部备用供电表达管理失效。不要让场景装饰直接证明 Q04 尚未证明的因果。
- 门、警报、战斗、普通搜刮、撤离和结算继续使用现有系统。新的地图布置必须单独做可达性、遮挡、AI 和恢复校验后才开放。
- 不把旧教学任务自动接成新剧情链，不创建 Q05/Q07/Q09/Q10。

本次修复的是实际入口和新档流程；此处记录保留资产的用途，不表示实验室翻新已经完成。
