# Adult containment subject base

Author: Quaternius. Official source: https://quaternius.itch.io/universal-base-characters
Official overview: https://quaternius.com/packs/universalbasecharacters.html
Edition: Standard / free; cost 0; acquired 2026-10-15. Licence: CC0-1.0, original notice retained.

The free archive actually includes only Superhero male/female body bases. This integration selects the adult male, not a Teen model or paid Source variant. Original archive/source hashes and modifications are in SOURCE.json. Raw archive retained outside the repository.

subject_base.gltf keeps source geometry, bind/rest skeleton and skin weights, with two missing upstream normal-texture URI suffixes corrected to the actual package filenames. Runtime patient clothing/material presentation is project-authored in a separate wrapper; no existing PMC or player source geometry is rewritten. This is an independent base silhouette, not a green tint of SciFi.gltf.
