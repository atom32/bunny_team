# Field Supplies Art v1 — provenance and modifications

2026-10-15. All sixteen new prop meshes, muted PBR materials, fictional B07 package layouts/text, labels, seams, stamped edges, pull tabs, cable coils, component details and icons were authored for this project. No third-party model, texture download or generative image/model service was used. No real-world commercial branding or another game's proprietary asset is reproduced.

Offline source: `art_source/supply_art_v1/build_assets.gd`. It reuses the project's earlier native mesh-array, bevel and profile helpers from `art_source/weapon_art_v1/build_assets.gd`, with new supply-specific geometry and static per-material mesh batching. Production scenes load saved ArrayMesh resources; no mesh generator runs in gameplay. Cloth normal grain uses Godot's native seeded FastNoiseLite/NoiseTexture2D, not a downloaded or AI texture. These are authored first-pass presentation props, not scanned/high-poly photorealistic assets.

All text uses the existing `resources/fonts/game_ui.tres` and `assets/fonts/noto_sans_sc/NotoSansSC.ttf`, covered by the included SIL Open Font License 1.1 (`assets/fonts/noto_sans_sc/OFL.txt`); no new font download or embedded fallback font. Godot's own dependency licensing remains governed by the project's existing engine distribution.

The newly authored portions remain internal project assets; this record does not assign a public or CC0 license on the project owner's behalf. Rendered PNG icons are unretouched transparent-background renders of these actual native scenes, generated by `tools/supply_art_v1_probe.tscn` in an isolated author copy. Full asset hashes are recorded in `ASSET_HASHES.json`.

The separate presentation lookup additionally reuses the unchanged prior Weapon Art Pack ammo carton and three fitting scenes. They are not included among these sixteen new props and retain their prior source/license records, including the MoCap Online restrictions on the extracted magazine reference. The original Noto font and all prior weapon/character/environment assets are unchanged.
